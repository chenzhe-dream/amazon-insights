# F-01 形态任务恢复流程修复（2026-10-12）

## 原因与改动

任务读取原来只恢复报告，没有将保存的 scope 回填到形态查询条件；当 marketShapeNode 为空时，重新采集按钮被禁用。现在显式读取任务会回填保存的站点、类目、起止月；带任务编号且类目为空的链接在父级 URL 恢复完成后回填。回填仅发生一次，查询条件在等待期间变化则保留新草稿，普通轮询不回填，旧请求无法消费新任务的恢复意图。继续使用已有 parent callback，只写 marketShape* 参数。
