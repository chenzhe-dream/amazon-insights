# 类目目录名称与链接范围修复

用户明确要求：有自定义名称时优先显示；外链只落在类目数字，不能覆盖旁边内容。

## 方案与实现

- 目录接口从当前筛选可见的收藏记录中读取名称，在重复任务绑定去重之前选择，防止较新的自动标题覆盖已保存的自定义名称。
- 排除应用生成的“类目 ID · 站点 调研”及历史导入带月份/任务号标题。同类目有多个自定义名称时按更新时间、收藏 ID 取稳定的最近项。没有自定义名称保持类目编号；原收藏名称和业务数据均不改写。
- 新增可选 `displayName` 字段兼容旧目录响应。左侧目录和右侧标题一致显示名称，编号仍保留。
- 自定义名称为普通文本；类目数字与箭头是宽度随内容收缩的外链。卡片其他位置仍负责选中目录，不打开 Amazon。
- 多站点保留各站点链接，站点文字与数字外链分开。
- 不涉及插件采集、重新分析、迁移或正式 31900 发布。仅更新 32900。

## 验证

- 先新增失败用例：旧实现不显示自定义名称，接口没有 `displayName`。
- PostgreSQL 回归覆盖默认名回退、去重前保留自定义名称、多个名称按最新修改选择，以及已有分类/分页/权限行为。
- 浏览器回归真实点击名称、报告数量、右侧空白、数字链接，验证外链与内部选中互不影响。
- 静态页面回归覆盖无名称和多站点数字链接。
