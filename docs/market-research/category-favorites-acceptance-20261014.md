从类目数字开始，下设市场总览、商品形态及价格带、类目关键词洞察、类目买家评论见解，再查看对应模块的历史报告。优化读取速度，保留全部历史记录。仅更新候选 32900，未发布 31900，也未删除或归档任何收藏。

## 原因与改动
- 昨天确认的层级仅存在于 32910 独立原型。实际 React 收藏页仍逐条列出导入的收藏。
- 旧接口翻页先读取全部收藏及其完整报告 output_json，再在 Node 中切片；用户等待时整个表格被替换成加载提示。
- 新增认证 catalog/history 接口，由 PostgreSQL 归组并分页。目录只返回类目及模块摘要；选中模块才加载历史页。报告正文仅在实际预览报告时读取。
- 同一个末级类目 ID 和完整路径归入一个目录；不同站点/月份清楚展示；同一 run 的重复收藏引用仅在展示计数时去重，不修改数据库；不同 run 保留历史版本。
- 四模块齐全：同类目、同站点、同起止月、同周期模式的四个模块均存在 ready 报告。仅表示有范围一致的完整报告集合，不冒充同一联动批次。
- 左侧类目目录、右侧四模块卡片和历史列表沿用 V2 配色。保留分组筛选/创建、收藏详情与元数据编辑；导出改为当前类目当前模块的筛选结果。
- 保留原 runId、完整 nodeIdPath、站点、月份、TopN/新品参数；预览不带 linkedApply/linkedBatch 等采集触发参数。
- 切换请求可取消，超时可重试；同查询缓存可在刷新期间继续显示，其他查询结果不会冒充当前类目。URL 保留类目、模块及类目目录页位置。
