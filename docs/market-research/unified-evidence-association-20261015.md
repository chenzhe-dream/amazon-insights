# 四模块综合开发结论：证据关联规则 v2

## 范围

按用户确认的有效性审查实施，仅更新候选环境 32900/32901。来源为当前联动批次已保存的四模块报告及冻结人工修订；无新增采集、翻译或模型调用。31900 不发布。

## 输入与关联

1. 总览：读取已知样本销量、均价、评分、样本数和新品链接数，保留实际月份、单位及样本身份。作为市场背景，不把总览样本销量归因给某候选方向。
2. 关键词：读取保存分类的人群、场景、属性标签及对应关键词。未确认来源月份的月搜索量明确标注，不能视为转化量。
3. 形态：读取当前保存版本的选中 ASIN、标题、人工形态及已知价格/币种。价格是采集时价格，不冒充历史月售价。只在完整六个日历月且上架日期明确的子样本计算新品历史销量占比。
4. 评论：只纳入所选 ASIN 的已保存摘要片段及主题来源 ID。截断片段明确注明；主题计数不是独立评论数，正负可能重叠。

需求到产品使用明确词条或完整短语匹配，不硬编码类目；复合属性要求同时匹配，明确的并列标签允许匹配其中一个。评论必须同 ASIN 且出现相关词条。否定词须直接修饰该属性，Non-Slip 不会否定折叠或儿童属性。

## 输出与边界

- 每个方向有状态、对应商品、参考价格及覆盖、四模块依据及来源、相反信号、缺口和验证行动。
- “可进入方案验证”表示文本证据链可复核，不表示购买归因、未满足需求、市场空位或批准立项。未知同义词/未覆盖语言不强行推断。
- 同指标的单位、实际窗口、分母与样本身份一致才判定数值冲突。不同口径分别展示，不平均；未知口径不声称一致。
- 同口径冲突会改变整体判断并增加 P0 核对行动。全部保存片段中的严重风险词单列人工核实；词表可能误报漏报，不代替完整合规检查。
- 单模块缺失只阻断依赖该证据的判断；其余已知分析保留。关键词原有“缺评论/价格”提示在跨模块取得资料后解释补充程度，不宣称已证实未满足需求。
- 规则编号、版本和限制随 v2 结论冻结。v1 冻结报告按原文读取，不重新推导或改写。

## 验证

- 新旧规则、数据提取、页面、人工修订、冻结存储、真实接口与代理：29 项通过；随后新增三类四模块保存输入链路测试通过（滑板车 US、落地灯 JP、户外包 DE，均为虚拟数据，户外包类目号为测试占位）。
- 覆盖不同 ASIN 不串评论、复合属性、超过30方向不丢弃、未知量不补零、历史月份缺失/重复、来源行号、截断片段、真实冲突及口径差异。
- 历史滑板车保存输入只读复核：100 商品、8 组需求、46 个保存评论片段；儿童和便携/折叠有同 ASIN 关联，其余6方向保留待补。无严重风险词命中不等于不存在风险。
- 完整虚拟调度与候选部署验收结果另记；不以源码测试代替线上验收。
