- 显式强制刷新保持新任务及来源刷新语义；不会覆盖旧报告。普通恢复不续写原采集时间。
- 额度耗尽、限流、本地排队分别传递；额度耗尽不自动重试，页面不再建议修改正确的类目名称。
- 修复刷新页面后旧 run 参数阻碍新联动结果绑定；仍保留用户主动编辑和手动选择历史报告的行为。
