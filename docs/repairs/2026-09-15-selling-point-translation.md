# 主要卖点中文翻译修复

本次改动限于竞品概览中的“主要卖点”及其原文采集、翻译接口。代码在 integrate-xydc-variant-20260905，侧边会话未重启或发布服务。

## 行为

- 默认显示中文翻译，不再混用规则摘要与英文残片；原文可折叠查看。
- 新采集保留 listingBullets 全部原文。历史数据仅使用仍完整的 strengths，提示内容不完整；不补造被截断的卖点。
- 按项目和 ASIN 请求；服务端校验登录组织、项目商品范围。当前原始商品目录仅支持美国站，其他站点明确提示暂无可核对原文。
- 复用现有大模型配置、资源并发控制和费用额度。逐商品翻译，同一原文只触发一份任务；按组织、ASIN、原文内容、模型及提示版本缓存到外部数据目录。
- 翻译条数、中文、数字参数和认证缩写进行检查；失败不会自动无限重试，页面提供重试入口。
- 新接口 GET/POST /v1/projects/:projectId/selling-point-translations/:asin 已接入后端和网页代理。POST 排队即返回，页面每 5 秒查询状态；切换项目/退出会取消页面请求。

## 验证与发布范围

单元与接口测试验证缓存、原文更新失效、失败处理、登录限制、请求字段约束，以及网页代理。浏览器使用模拟接口验证中文显示、失败重试、折叠原文、刷新复用。原文采集测试验证 5 条长原文完整保留。

真实模型调用和正式页面尚未验收。需由主窗口统一构建并重启网页与 Agent 服务后，使用已有项目检查翻译结果；本次没有新增数据库迁移或模型密钥配置。
