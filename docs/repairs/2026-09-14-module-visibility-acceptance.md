# 钉钉人员模块可见性验收

## 使用方式

进入「用户与使用统计 → 模块可见性」，搜索钉钉人员，点击「配置可见模块」，勾选九个模块并保存。对方刷新页面后读取新设置。没有个人配置的人员保持原显示范围；全部取消勾选会显示「暂无可见模块」。

配置列表每页 10 人，支持搜索和翻页。名单展示姓名及账号以区分同名人员。抽屉支持全选、清空、取消、保存；他人同时修改时提示重新打开，防止覆盖新配置。

## 范围

- 九项：市场调研、竞品概览、VOC、关键词调研、新品定义、立项前确认清单、竞品流量分析、收藏夹、用户与使用统计。
- 菜单、子页面、收藏业务入口、同步完成后的快捷入口遵循相同配置。直接打开隐藏页面时跳转到首个可见页面；全部隐藏时不挂载业务页面。
- 沿用专用用户状态查看资格管理配置；勾选用户统计不会赋予原本没有的查看资格。管理人员隐藏统计模块后仍保留「模块可见性」配置入口。
- 仅调整界面显示，不改变业务 API 授权、分析任务、队列或旧数据。无新增心跳；配置在登录会话请求时读取。
- 原 PostgreSQL 新增 0050 配置表。按组织及实际登录身份读取，写入审计，乐观版本冲突保护。未给任何现有人员预置限制。
