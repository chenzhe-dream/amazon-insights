# 雪地滑板 VOC / 新品定义串入轮式滑板车建议

## 已核实的问题

涉及 B01M119PTN、B00P8J6AQG、B0FV2T2SP4、B06XJP1N12、B0DP9H584S、B0DP5P89N1、B08NTVLQWD。

这 7 个商品目录类目均为 Snow Sleds。读取 PostgreSQL 当前手工 VOC 后，没有发现 PU 轮、密封轴承、三轮倾斜转向等机械配置；原文中存在中文“雪地滑板车”，但不代表有车轮。

根因有三层：

1. 前端与同步脚本的产品族识别仅匹配 scooter/滑板车，Snow Scooter 因此误入轮式滑板车动作模板，旧目录中的 productFamily 还可能保留错误值。
2. 最终定义、关键词人群转参数、交叉分析存在不区分类目的 Deck、轮距、转向等固定建议，修正产品族后这些兜底文本仍会泄漏。
3. VOC 人群/场景仅取竖线左边内容，导致“冰面｜不适合使用”丢失否定；同时关键词的人群、年龄、场景直接覆盖 VOC。例如 toddlers 不足以证明该雪地产品适合幼儿。第一行含竖线被一律当作表头也会丢失有效记录。

## 修复

- Snow Sleds / Snow Scooter / 雪地 / 雪橇等明确上下文优先识别。当前归入通用分析路径，暂不新增未经验证的雪地工程配置模板。
- 页面入口与分析模型按标题/类目纠正历史目录中的错误族标记；同步脚本同样修复。无需重跑采集或修改原始 VOC。
- 非轮式滑板车使用实际主题生成交叉分析；移除最终定义中无条件出现的轮式结构建议和泛用模板中的灯具专属风险。
- 人群/场景的否定条件保留为“不适用”警示，禁止被规范化为正向场景；原文明示最佳/主要适用的信息保留并优先用于建议。仅跳过真正的表头。
- 原始 VOC 不删改；不适用主题仍保留在汇总中。新品定义不再用关键词人群、年龄、场景直接替换 VOC 结论，关键词仍展示为待核对证据。

## 验证范围

- 23 项测试通过：雪地分类、历史错误族标记、否定语义、人群/场景冲突、关键词功能分层、页面渲染、现有滑板车和灯具 VOC 特征回归。
- 读取上述 7 个 ASIN 的现有目录和数据库 VOC，执行完整本地立项与最终定义生成链路，核对机械配置泄漏。
- 本次修复动态页面，不批量重写既存的历史报告。

## 边界

不同竞品的年龄、体重和场景条件可能相互不同；保留原始证据供业务核对。通用路径不会凭类目自动承诺材料、轴承、轮子或某项技术结构，也不代表工程设计已经验证完成。
