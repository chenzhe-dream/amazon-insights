# 子体订单配色与中文名称

## 范围

OpenSpec：`align-variant-share-colors`。仅修改颜色展示，不改采集、订单统计、分母、排序和 ASIN 身份。工作区：`integrate-xydc-variant-20260905`。本次未发布。

## 规则

1. 仅使用当前子体的颜色维度，不借用父体图片、兄弟子体或尺寸字段。
2. 基础色、十六进制色码、离线词典名称优先；带连字符的完整词典名称先按单色识别，再处理明确双色。
3. 名称仍未命中但含唯一基础色词时使用近似色；没有可靠色系或双色中的一部分未知时使用中性斜纹。透明色使用棋盘格。
4. 来源中文标签优先，保留已有中文翻译；缺少中文时用“近似某色（原名）”。常见 Aqua Blue 显示水蓝色。原始属性保存在悬浮说明中，不修改原始数据。
5. 同色不同 ASIN 保持独立，卡片、图例、表格和月度图共用颜色映射。浅色有内边线，文字选择黑/白高对比色；双色百分比加白底。窄条文字缩放，极窄条隐藏文字，完整百分比仍可在悬浮与明细中查看。

## 数据与费用

固定 meodai/color-names 提交 `563a7be191d9fa8571bfe54f5f6d97f0a07808b5`，MIT 许可随数据保存。

- 31,918 个名称；名称到色码的离线词典，非实物取色或逐字翻译服务。
- JSON 796,788 字节；gzip 292,333 字节，约 286 KiB。此数字是词典本身，不是整个页面构建体积。
- `node scripts/update-variant-color-catalog.mjs` 可按固定版本重新生成，记录 CSV SHA-256、条目数和体积。
- 本次使用离线中文色系兜底，未接入普通翻译服务；无大模型、翻译 API 或运行时外部词典请求。
- 色块均为示意，明确双色的分色面积不代表实物面积。

## 校验与预览

测试覆盖色名解析、原翻译兼容、来源中文、稳定 ASIN 映射、订单汇总、月度悬浮、年度明细和手机交互。浏览器测试阻断外部网络，验证没有新增翻译调用。

最终验证：6 个定向测试文件合计 **36/36 通过**；`npm run typecheck`、改动涉及文件的 ESLint 和 `openspec validate align-variant-share-colors --strict` 均通过。独立代码复审无剩余重要问题。未执行生产构建或发布。
