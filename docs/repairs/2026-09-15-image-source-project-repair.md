# 收藏图片重处理与导出入口修复

用户授权：修复图片“重新处理”错误提示，并先隐藏顶部“导出对比报告”入口。

证据：B01M119PTN 的原分析项目“儿童雪撬板”有两次基础同步，最新 listing/image_remarks 均 ready。同批商品的 keyword-compare 收藏拥有独立 ID，仅有本地收藏记录，没有对应分析运行；历史日志查询该收藏的分析项目接口为 404。原历史指针读取把 404、权限、网络、结构不匹配一律折叠为 null，页面误导用户重新同步。

实现：
- 新的关键词、推广能力、确认清单收藏保存 sourceProjectId，通过已鉴权 Agent 接口创建；后端验证来源组织、分析项目类型、站点及商品包含关系。
- 旧收藏不根据 ASIN 自动绑定。在图片页提供显式“关联并打开”选择，保存成功才进入来源分析项目。已有关联可直接打开；来源不可访问或范围变化时不替换为其他项目。
- 收藏图片保持可查看，图片任务只在原分析项目提交。关联、打开均不启动采集。
- 历史任务读取区分登录失效、权限、HTTP 错误、网络、关联不匹配和真正没有运行记录；保持项目、站点、ASIN 与运行身份检查。
- 顶部不再渲染“导出对比报告”，保留已有报告数据及读取能力。

验证：接口与指针 34 项、图片与导航 19 项、存储与图片执行脚本 9 项通过；浏览器验证旧收藏选择、503 重试、保存后恢复且无采集 POST。全仓类型检查通过。首次广义接口源代码断言引用的是旧 VOC effect，已按现有带 AbortController 的恢复实现更新，保留恢复与取消检查；React 图片测试单独按浏览器条件执行。
