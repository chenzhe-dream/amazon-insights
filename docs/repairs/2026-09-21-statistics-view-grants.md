# 用户与使用统计独立查看授权

## 问题与修复

旧模块勾选只控制可见性，后端另有统计查看资格，因而普通用户即使全选也看不到入口。原统计资格又用于模块管理，直接放开会连带提权。

本次增加单人配置中的「允许查看用户与使用统计」开关，开启时自动选中统计模块。查看范围为本组织人员账号、在线与登录状态、页面使用和分析用量；不会授予模块配置、其他管理权限或改变用户角色。

统计接口和会话使用独立读取判定，模块配置接口继续使用原管理资格。已有系统所有者与指定人员资格保持不变，新增开关仅管理独立授予的统计权限。撤销后原会话下一次统计请求立即被拒绝，刷新后同步导航。

## 数据与交互

- PostgreSQL 迁移 0055 在 user_module_visibility 新增 statistics_view_granted，默认 false，历史及新用户默认模块不自动授权。
- 个人保存显式传 statisticsViewGranted；旧客户端或批量保存省略则保留已有授权。默认设置契约拒绝该字段。
- 显式授权 true 必须同时显示统计模块；模块隐藏时新增授权不可用于后端读取。
- 授权与模块使用同一目标行锁、version 和审计事务，版本冲突不会部分修改。
- 批量失败剩余一人后，重试仍保持批量的授权不变语义。

30 项定向测试通过，包括独立 PostgreSQL 容器迁移、授权与撤销、会话旗标、统计接口、跨组织拒绝、禁止自授权、模块配置 403、历史与默认全选不授权、CAS 冲突、审计、所有者保护以及正式 Web 代理透传。

全仓类型检查、修改组件及新增测试的定向 ESLint、OpenSpec strict 校验通过。测试证据位于 `.superpowers/sdd/statistics-final-tests.log` 等文件。
