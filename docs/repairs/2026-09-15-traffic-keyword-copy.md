# 流量词对比：快捷复制与批量复制

根据业务截图反馈补充当前矩阵的复制交互：每行复制、勾选复制、复制当前列表。

## 范围与行为
- 每行显示复制按钮；首列提供勾选及全选当前列表。
- 批量只复制关键词文本，每行一词，沿用当前筛选与排序。当前列表最多 150 词，按钮显示实际数量，不声称复制全部未展示结果。
- 筛选、产品范围或可见词集合变化时清空选择和旧提示；排序不改变选择，复制顺序跟随列表。
- 优先浏览器 Clipboard API；不支持或拒绝时尝试文本选区复制，兼容局域网 HTTP。两条路径均失败时展示可选中的只读文本。
- 复用现有矩阵和按钮风格；不改关键词算法、后台接口及数据库。
