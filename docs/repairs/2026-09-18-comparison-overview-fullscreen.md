# 竞品参数总览全屏

用户要求在竞品参数总览新增全屏查看。使用原生 modal dialog 承载同一份表格，在普通模式中保持原卡片布局，展开时占满页面视口。没有使用需要特殊浏览器许可的屏幕全屏 API。

- 右上角“全屏查看 / 退出全屏”，支持 Esc。
- 内容不重新挂载，保留表格横纵向滚动和子组件状态，避免切换触发重新取数。
- 全屏显示固定表头、首列，表格使用剩余高度；手机支持横向滚动。
- 模态状态隔离背景交互、锁定页面滚动、循环键盘焦点；关闭恢复按钮焦点，关闭或卸载时恢复原滚动设置。
- 只修改参数总览容器，不调整字段、分析、数据接口或其他模块。

浏览器回归：桌面及 390px 布局、进入/按钮退出/Esc、滚动和输入状态保留、单次挂载、首列固定、焦点循环、卸载恢复均通过。新组件和测试 ESLint 通过。截图位于 `test-results/comparison-overview-fullscreen-desktop.png` 和 `test-results/comparison-overview-fullscreen-mobile.png`。
