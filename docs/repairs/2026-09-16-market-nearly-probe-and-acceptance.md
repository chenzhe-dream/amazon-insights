## 逐模块操作和通过标准

### 1. 市场总览

1. 填好站点、完整类目路径、月份，点击“筛选市场”（或搜索），先看基础类目指标。
2. 检查返回类目确实是中性笔，站点US、币种USD，月份与输入一致。空字段应为未知或缺口，不能伪装成0。
3. 需要验收完整总览分析时，在“总览分析与报告”将起始月也设为2026-08，点击“开始总览分析”。这与基础筛选是两个独立入口，会产生额外采集及分析步骤。
4. 检查各来源步骤、保存的数字报告和分析解释。解释应有数据依据；分段失败应保留已成功的数据，并提供原因/重试入口。
5. 保存任务地址，刷新并恢复，确认恢复读取不会重新启动采集。

### 2. 商品形态及价格带

1. 检查站点、类目、起止月正确，商品池先设10。
2. 形态目录按每行“名称|判断依据”填写：

```text
按动式|标题或可见商品证据明确为按动伸缩笔尖，例如retractable或click
带笔帽式|标题或可见商品证据明确带可拆卸笔帽，例如capped
```

3. 点击“采集商品并生成形态建议”。检查列表实际商品、ASIN与中性笔相关，图片/价格缺失时有明确显示。
4. 模型建议需要人工核对；证据不足的商品保持未分类。核对商品选择与每个商品的形态，价格带下界可设 `0,5,10,20`。
5. 点击“确认并重新计算”才保存统计版本并生成形态/价格带报告。未确认时显示待保存是当前流程，不代表采集卡住。
6. 检查数量、价格带边界、未知值和未分类组。再修改一个分类并保存，确认生成新版本且旧版能打开；分类修改不应重新抓商品。
7. 商品列表有多页才测试分页；拖动列后表头、数值应对应，重置顺序应可用。

### 3. 类目关键词洞察

1. 输入 `gel pens`，填写上述类目说明；展开“类目范围与采集设置”，确认完整路径、月份、1页、上限10。
2. 点击“查询”。检查关键词词池、指定月份搜索量、趋势与分类；没有参考月数据时必须保留缺失，不能用别的月份冒充。
3. 查看分类依据，重点排除笔筒、触控笔等不同产品。关键词表达的愿望不能直接成为商品已具备的结构事实。
4. 美国站可能有SIF ABA补充步骤，它与基础Sorftime词池来源不同；逐项记录失败原因，不因补充缺失否定全部成功数据。
5. 修改一个明确错误的标签/归属并保存，刷新读取，核对修订和历史版本。实际竞价建议不能当作真实CPC。

### 4. 类目买家评论见解

1. 确认同一站点、类目与月份；展开“分析月份与样本设置”，主题样本3、商品池10。
2. 点击“拉取见解”，等待商品池、主题采集、归类和报告步骤。
3. 查看实际取得的ASIN数量及各商品来源状态。有主题则核对书写、握持、漏墨等内容是否来自对应ASIN；没有主题应明确缺口，不能自动补写。
4. 展开主题来源检查原主题、ASIN、正负向计数与提及数。Customers Say主题份额不是独立评论发生率；所选月份也不等于将评论过滤为该月新增评论。
5. 报告不应出现无来源的灯具、滑板车等建议。刷新任务地址，确认结果恢复与范围正确。

## 通用验收与反馈

- 四个入口可切换；站点、类目和报告范围明确。修改查询条件后未重新查询，旧报告必须能被识别为旧范围结果。
- 收藏查询条件和已有报告，另一位有权限的同事可查看；打开收藏本身不触发新采集。
- 缺失和失败须分别标明来源/原因，不应一直无说明地“处理中”。
- 优先恢复已有任务；失败先点对应步骤重试，不要反复点击整套新建分析。
- 涉及更多月份、更多ASIN或更多关键词时会增加调用，不在首轮全量验收。
- 记录：模块、任务地址、输入参数、预期结果、实际结果、截图。看到错类目、错月份、串项目、已保存修订丢失，均记为未通过。
