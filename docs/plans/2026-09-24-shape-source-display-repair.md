# 商品形态已采集数据展示修复

## 根因与范围

- 商品图片已在供应商原始响应中入库，但公开字段白名单未投影 imageUrl，商品表固定渲染 ASIN 占位。
- 看板和月销量只读取 latestRevision，采集成功但尚未人工分类时无法查看已保存的来源数字。
- 单月任务没有近三月、近半年及前两年数据；成本、毛利、退货率等来源未提供。不能补零或从价格推测利润。

## 实施

- [x] 从冻结来源投影 Amazon HTTPS 图片地址及证据路径；失效图片保留占位和原因。
- [x] 增加独立的 collected-source 只读汇总；按照任务固定商品池与研究月份校验来源，缺月不补零，共同比较只纳入各月销量有效的商品。
- [x] 沿用当前看板布局，人工保存前显示来源汇总、参考月销售额及月销量。已保存的分类报告继续使用原版本数字，不冒充人工确认。
- [x] 表格未保存时读取来源月销量；未采集的周期明确提示，成本和准入缺失单独解释。
- [x] 回归覆盖图片白名单、历史月份缺失、零值、旧版本准入、隔离数据库读写、原始人工分类流程、桌面及移动样式。
- [ ] 正式发布后核对同一个真实任务的图片、看板、刷新恢复和数据库无新增采集/修订记录。

## 已知边界

本次不扩大采集月份、不补写人工分类、不调用模型、不迁移数据库。来源看板按采集商品池统计，人工保存后按该版本选择与规则统计。跨月销售额与类目级垄断、利润、退货等未经定义或缺少来源的指标仍保留未知原因。

## 发布与回退

仅将本修复提交从隔离分支挑选到正式发布分支；保留正式目录已有生成数据的文件哈希。通过 manage-formal-stack.ps1 -PublishCode 发布。必要时回退本修复提交并使用同一发布流程，避免覆盖其他窗口数据。发布前正式基线 cfdd8f0c。
