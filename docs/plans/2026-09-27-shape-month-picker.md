# 第二模块年月快捷选择

用户已指定使用成熟年月组件，直接替换第二模块起止月份控件。采用 react-datepicker 9.1.0（支持 React 19）月份面板加年份下拉；相比保留原生控件便于跨年选择，相比引入整套 UI 库改动范围更小。

输入、查询与缓存仍使用 YYYY-MM；中文月份面板，年份下拉及前后年按钮，保留手输、禁用状态和原有月份校验。不改查询或采集逻辑，不联动其余模块。
