# 第三模块恢复原版自动分类

用户已要求先向压缩包原版靠拢；本轮落实原版已有自动规则分类流程。沿用当前独立候选分支，正式发布前重新核对其他窗口基线。

原版依据：reference/app/keyword-classifier.ts（与当前同名文件哈希一致）、reference/app/lib/product-keyword-demand-analysis.ts 中 detectW1、detectW2Label、detectW3、W4_FAMILIES、buildClusters。

采用：从已保存原词生成版本化本地分类，恢复12类含义、W1–W4以及产品+场景+人群需求簇。表格、五维统计、需求簇和人工草稿使用同一份分类。原版品牌词排除需求簇；词量缺失仍保留未知。现有人工版本原样保留，优先恢复人工草稿。读取已有任务即可显示自动分析，不重新采集、不调用模型。

不采用：仅修改展示文案（无法恢复流程）；重新启用模型（原版这些分类本就来自规则）。不照搬原版缺数据补中间分或将未知搜索量当零的做法；词典覆盖有限时明确标为规则匹配。
