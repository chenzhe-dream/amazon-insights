# 区域一：市场总览缺失输入评分

2026-09-29，用户批准按四区域逐项推进；本轮仅修总览评分缺失语义。

## 已实现

- 原版v6评分/价格算法文件不改，原文件SHA检查保留；新增 `observed-inputs/1` 投影校验。完整输入沿用六维权重25/20/10/15/15/15和等级。
- null、空白、布尔值、无效数字不再通过Number转换为有效0；来源明确0保留，负毛利仍为有效观察。
- 逐维确认必要输入，缺失维度分数为null，说明具体依赖；六维未齐全时总分、等级为null，不补半分、0分或重新折算100分。
- 趋势检查遵从原版预处理，要求有效比较窗口和非零基期；同比单独检查同期关键词集合，防止缺基期词导致虚假增长。已知全0关键词不阻断有效的合计趋势。
- 价格数量及销量完整时允许原版推导占比，不额外要求原算法未使用的asinRatio；全部参与价格带须有真实毛利样本，阻止默认模型带来的高毛利评分。类目成本参数缺失时省略默认成本估算文案，不取消有真实依据的价格评分。
- 关键词部分失败、浏览量冲突/截断、分布截断传递到依赖维度。跨维度机会、风险和最终文字均检查依据。
- 原卡片和雷达位置保留；未知轴不画成0分，不形成闭合面积，不显示综合百分比；有依据的点及对应分项保留。当前读取按已保存来源应用新校验，明确提示不改写历史快照。
