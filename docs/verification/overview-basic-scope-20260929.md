# C6：历史总览与基础概览范围对应

## 根因

市场基础采集历史加载后默认选择最近一条。总览报告从URL/任务编号独立恢复，只在筛选为空时恢复筛选，未将报告范围交给上方基础卡。因此同屏可能显示最新的滑板车基础数据和旧落地灯详细报告。

## 本轮修复

- 详细报告传递加载、失败、就绪及当前范围给基础概览；自动显示最近30条历史中与报告匹配的基础记录，不再默认混用其他类目。
- 匹配站点、规范化类目、报告结束月（或最近30天）、TopN和新品窗口。两条完整路径不同时即使叶子相同也不混用；裸节点允许匹配对应叶子。
- 基础记录是同范围的独立采集记录，不宣称它与详细报告属于同一采集批次。卡片仍显示真实采集时间；多月总览的基础卡对应结束月。
- 两种接口返回顺序均不抢先显示不相关记录；没有匹配记录时明确限定“最近30条”，不声称全部历史均不存在。
- 手动查看其他基础历史仍可用，范围不同时显示提示，并提供“返回报告对应概览”。历史刷新不擅自撤销手动选择；新总览任务不沿用旧任务的手动选择。
- 从基础卡打开分析报告时同步完整筛选条件，避免只同步类目而保留其他记录的月份/站点。
- 不修改来源、评分、7天缓存、历史快照，不因读取或匹配发起采集。

## 验证

新页面回归先失败，确认旧版无法等待报告范围或按其匹配。修复后覆盖基础历史先返回/报告先返回、不同类目/月/TopN/新品窗口、手动选择与刷新、返回对应记录、无匹配与空历史、匹配记录采集失败、历史接口失败、任务读取失败、最近30天、零采集写请求；纯匹配测试覆盖站点、完整路径冲突和裸节点。

连同7天缓存、历史版本、重新采集、最近30天及原基础显示回归，共15项检查通过。TypeScript检查通过。正式入口截图、历史不可变及发布版本完成后追加。

范围到C6为止；其他原版能力和界面待用户验收、真实外部缺口及两项旧测试债继续独立记录。
