# 模块一二管理员辅助工具整合

## 用户授权与范围

用户要求整合新增辅助入口，并且只有管理员能看见。每个模块页底新增一个默认折叠的“管理员工具”，与业务报告分开。沿用 `app/page.tsx` 的已认证admin判断，不读取URL或本地偏好决定权限；普通账号不挂载该面板及工具内容。

本轮只改变界面组织与显示，不变更业务API授权、计算、7天缓存、草稿数据库保存或采集请求逻辑。手机号布局未扩展。

## 对照原版后的处理

原版依据：`project-notes/amazon-insights/ui-parity-20260914/reference/app/sellersprite-market-overview-section.tsx`、`sellersprite-market-report.tsx`、`sorftime-category-dashboard-view.tsx`。

| 模块 | 后来新增的辅助入口 | 本轮处理 |
|---|---|---|
| 市场总览 | 完整基础指标与原始比例、数据口径与范围 | 移到管理员工具，移除业务表内的核对入口 |
| 市场总览 | 已保存指标与原始来源、分析维度覆盖与缺口、本报告分析规则、报告版本与来源身份 | 合并到同一管理员面板 |
| 市场总览 | 分析设置与任务管理、采集历史与状态 | 合并并按admin显示，原恢复/重试/取消/历史事件保留 |
| 商品形态及价格带 | 恢复已有形态任务、刷新任务状态、来源步骤及重试/取消 | 移到管理员工具；普通账号保留错误和数据不完整提示 |
| 商品形态及价格带 | 四张统计表的数据完整度、缺失商品与毛利补齐明细 | 集中到管理员工具，各组标明上架年份/形态销量/形态价格带/品牌价格带，仍对应各自筛选范围 |
| 商品形态及价格带 | 综合结论的数据范围与口径 | 移到管理员工具 |

保留普通业务功能：查询与重新采集、图表及报告、商品池数量、形态输入/批量编辑/名称管理、筛选排序、草稿保存/冲突处理、缺失与失败说明。新增不等于调试功能：已批准的名称管理和自动保存属于日常业务，不能一起隐藏。历史兼容报告仍保留业务表格与编辑功能。

实现使用一个模块级工具容器，子组件通过React portal放置辅助内容，保留原有状态和事件回调。切换模块时容器重置为折叠；角色降低时工具内容立即卸载，业务草稿不丢失。
