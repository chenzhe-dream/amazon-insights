# 模块一二表格尺寸、布局、配色对齐

用户要求向压缩包原版靠拢。本轮限桌面报告展示；不是重新设计业务功能，也不声称全站逐像素一致。

## 原版依据与本轮变更

对照 `project-notes/amazon-insights/ui-parity-20260914/reference/app/comparison-layout.css` 与 `sorftime-category-dashboard-view.tsx`。

| 区域 | 之前差异 | 本轮采用的原版样式 |
|---|---|---|
| 商品形态输入 | 高36、字号13 | 高28、字号10、边框#dbe3ed、紫色聚焦边框 |
| 商品默认列宽 | 排名50、品牌90、日期85、毛利80、趋势145等 | 对应原版44、88、72、72、128；产品仍240 |
| 形态列 | 160 | 120，容纳原版96宽输入与24边距；拖动下限96 |
| 商品工具栏 | 文字16、标签上下排列、搜索缺少完整边框 | 11/12字号、横向标签、30高搜索框，8px间距 |
| 商品行/固定列 | 固定列#f8fbff与原版行色不一致 | 统一选中行#fafcff、表头#f7f9fc |
| 年份/形态/价格带汇总 | 首列th间距偏大、总计未使用原版色、数值左对齐 | th/td统一6px 8px、字号10；数值右对齐；小计#f3f7fb、总计#eef4fa、价格带缩进14 |
| 总览指标卡 | 数字25、间距14、padding16、灰蓝边框 | 数字20、间距10、padding12px 14px、紫色浅边框#e9d5ff |

批量列65、操作列70是适配当前功能的保留项，不为机械一致造成遮挡。用户已保存的列宽继续使用，不覆盖其显示偏好。数据完整度继续默认折叠；先前确认的图表尺寸、单月趋势、固定商品列、移除确认、自动草稿都保留。只修改4个UI/CSS文件，无后端、评分、统计、采集或数据库逻辑改动。
