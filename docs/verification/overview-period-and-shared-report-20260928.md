# 市场总览类目解析、最近30天与共享报告修复

本轮按用户明确批准的顺序修复，缓存时限不改。

- 类目编号精确匹配后有多条路径时，恢复原版按来源顺序取首条的行为；不选取其他编号的首条搜索结果。
- 最近30天恢复原版无 month 的供应商请求。基础查询保存 last30；详细报告使用独立 overviewPeriod=last30 身份，已结束月份仅作为历史序列截止月，不作为滚动快照的请求月份。滚动来源记录 trailing-days/30 与真实采集时间，展示为最近30天。自然月路径与旧报告保持原口径。历史查找区分两种周期。
- 报告重放从任务创建者身份改为当前已授权阅读者身份；组织隔离、原始来源哈希、不可变报告校验不变。离职或停用创建者不影响同组织正常用户读取历史报告。
- 浏览器地址混用滑板车筛选与落地灯任务时，保留已保存报告并明确标示条件不同；不能据此把落地灯结论当成滑板车。

验收：新增多路径、last30 请求、完整持久化报告、停用作者后的跨成员读取与拒绝跨组织读取测试；再做正式页面与供应商验证。
