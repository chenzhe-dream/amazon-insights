# 区域二、三修复验收

2026-09-29。用户授权“先修复完第2–3项”。以压缩包原版为业务基准；本轮不处理区域四供应商缺口。

## 区域二：商品形态

- 发现分组及合计月均按有值链接计数，缺失时会抬高结果。新版本 `shape-all-links/3` 恢复全组链接分母；缺失周期月均为空。已知销量仍展示并说明已知小计/占比分母。
- 上市前明确不适用的链接仍计入原版全组链接分母。实际0保留，上市日期冲突不伪造年度销量。
- 原版综合实际依赖近3/6月，不依赖年度；解除年度误阻断，同时拦截缺日期、价格带、毛利的确定性综合判断。部分毛利独立结论保留原版有效样本口径，全缺不出结论。
- 形态趋势需2024和近3/6月，2025不再误阻断。价格带结构按原版可用历史回退，缺失年度的派生份额全部置空，不以部分销量伪造完整年度占比。
- 完整输入直接对比原版纯函数，权重、阈值、最近3/6个返回点及年度列保持。旧v1/v2快照保留原计算语义和尾行小数精度；新草稿使用v3，不写回旧快照。

## 区域三：基础表

- 新基础采集保存可选 `tableMetrics`：头部均销/均额、平均/头部BSR、平均卖家数、三种卖家比例、三种集中度、新品占比、商品总数、退货率及同类目退货率。
- 头部为来源Top N合计除N；研究接口CR及新品0–1比例按原版乘100，统计接口新品比例直接使用；卖家与退货率沿原版百分数。
- 旧基础记录未保存raw，不能从哈希恢复丢弃的字段。已有完整总览报告从其冻结来源只读重建整行，通过run/attempt/hash、类目、站点、周期、币种、Top N和新品窗口绑定。不会与不同时间的基础任务拼接，最近30天也不跨快照混用。
- 旧基础记录和旧API响应继续可读，手动查看其他基础历史优先；切换报告/读取失败不串用冻结行。保留数据库草稿、原卡片与操作结构。
