# 模块一二管理员工具整合

用户已授权合并新增辅助入口，且仅管理员可见。沿用业务计算、数据库与采集逻辑。

设计：每个模块页底一个默认折叠的“管理员工具”面板；由页面已认证的admin角色开关启用。嵌套组件把已有核对内容放入该面板，保持原状态和事件。普通账号不挂载工具内容。日常查询、报告、形态编辑、草稿保存、错误与缺失提示继续显示。

模块一：合并原始指标、范围说明、报告规则/来源身份、任务设置与恢复/重试/取消、采集历史。模块二：合并任务编号恢复、来源步骤与任务操作、分表数据完整度与毛利缺口、数据范围口径。保留原版具备的形态管理、筛选与商品数量配置。
