# 市场总览缺失输入评分修复实施计划

用户已批准2026-09-29四区域方案。本次只执行区域一，完成、发布、验收后再进入下一地区。

**Goal:** 完整输入与原版v6同分同结论；缺失、无效或不可计算输入不能变成零值、默认分和确定准入结论。

**Architecture:** 保留原版纯评分文件及其哈希测试。冻结来源适配层保留缺失语义；新增输入依赖校验层，分别判断六维评分和文字结论是否可用。返回可空分数、逐维缺口及校验版本，界面保留现有卡片和雷达位置，未知不绘成零分。读取只生成新版投影，不覆盖历史快照。

**Tech Stack:** TypeScript / Zod / React / node:test / Playwright / PostgreSQL。

## 约束

- 不改变25/20/10/15/15/15权重、等级阈值及完整输入下的原版运行表达式。
- 不将剩余维度重新折算100分；任一维度缺必要输入则总分、等级为空。
- 真实0必须与null、undefined、空字符串、无效数字区分。趋势基期为0导致比率不可算必须说明，不伪造增长。
- 不修改商品形态月均、基础表字段和跨数量缓存；后三者留后续区域。
- 不重做页面布局；桌面验收即可。保存的历史数据不写回。

## 验收样例
