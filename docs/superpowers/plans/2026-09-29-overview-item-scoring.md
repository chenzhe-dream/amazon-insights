# 市场总览逐项评分与旧报告补采

用户已批准上一轮列出的四步修复，本计划记录实施细节，不重复申请授权。使用 writing-plans 与验证技能，在已批准候选区执行。

**目标：** 原版完整输入同分；缺项仅阻断依赖该项的分值，展示已确认分值而非默认分或折算总分；补采生成新任务；旧计算版本可对照。

**设计：** 保留 observed-inputs/1 函数、原版 v6 文件及已有冻结报告。新增 observed-items/2 逐项评分，条目记录依据状态、分值与缺口。新任务冻结 scoringVersion；旧报告 API 保留原 originalSynthesis 并提供独立 scoreReview，UI 明示新版复算及此前校验切换，不能将复算当成历史保存分数。完整维度沿用原公式，有缺项的维度显示已确认分，不连成完整雷达；总分与评级仅六维完整时生成。普通用户保留简洁评分解释，技术来源仍归管理员。

**评分边界：** 原始分量、权重、四舍五入、上限及等级均按 v6；市场需求的规模与增长分别封顶后各乘 12.5/20；成熟度基准10分仅在有实际可用观察时展示且标为部分。真实0有效；未知不参加判断、不获取“非下降”奖励；成本模型只允许作为明确估算说明，不作为真实毛利评分。缺口列表去重后区分评分项，不能声称接口失败数量。

**补采：** 使用既有完整 rules-v4 采集链路，按当前报告冻结站点、类目、月份范围、TopN和新品窗口新建，绕过已保存报告查找；不修改旧任务、不跨研究拼接来源。新增简洁缺口提示和入口。实际采集结果缺失时显示具体来源状态，不承诺供应商必然有数据。
