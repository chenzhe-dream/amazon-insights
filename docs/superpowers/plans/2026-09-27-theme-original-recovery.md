# 第四模块原版恢复实施计划

用户已批准 `docs/market-research/theme-original-audit-20260927.md` 的功能对照及修复方向，本计划落地该批准，不重新要求确认。

**Goal:** 恢复 Sorftime 选样、补图、精确同名归并、原版中文规则、1.2 倍分栏和显式重新采集。
**Architecture:** 新任务使用 `market-theme-flow/rules-v3`；保留旧流程及历史输入与报告。复用已有 Sorftime category_report / product_detail 采集器。主题精确归并保存为 local-rule 标签与映射，使用同一冻结统计重建修订。模型不启用。
**Tech Stack:** TypeScript、Zod、PostgreSQL、React、node:test、Playwright。

## 约束
- 当前隔离候选工作区，正式服务不随代码编辑自动改变。
- 各模块独立输入，不接通模块间自动选样或排除联动。
- 保留卡片和历史入口、异常校验；不补造计数、翻译或图片。
- 旧 rules-v1/v2 报告保留旧分栏和映射结果。
- 图片补充失败不丢失成功主题；重试仅针对失败步骤，旧报告可读。
