## 后续顺序与通过标准

1. **关键词单模块**：US / `1063294`（Floor Lamps），核心词 `floor lamp`，研究月份选供应商可提供的完整月份。验证提交、等待、部分失败、定向重试、规则报告、人工分类保存、刷新历史；数值 0 保留 0，缺失不补 0，推荐竞价不当作实际 CPC。先核对原版操作流程，再处理真实来源缺口。
2. **评论见解单模块**：相同测试类目，检查商品样本、原主题、正负提及与覆盖；排除一个样本、恢复、刷新，确认旧报告不变且不重采。全部失败显示具体缺口，不生成虚假主题。
3. **用户分别验收**：沿用现有导航、卡片、表格和历史入口，核对等待/成功/失败页面及窄屏。浏览器连接恢复前，不宣称 UI 最终验收通过。
4. **四模块联动**：单模块通过后再实现和验收总览类目向其余模块填充；在第二、三、四模块手改类目不影响其他模块，不自动触发未确认的分析。
