## 1. 用户确认的目标

- 将“变体结构与商品页表现”改为用户参考图的双列紧凑竞品卡片：份额条、子体表格及展开详情。
- 数据使用西柚订单量，不使用评论数、流量得分或其他供应商销量替代。
- 优先使用经过官方文档和实测确认的父体聚合结果；无法直接取得时，允许将同一父体的子体数据汇总呈现。
- 默认展示、订单份额、排序与本模块分析结论统一采用近12个月。近30天不作为默认，不与年度数据混算。

## 2. 数据能力与选定方案

已检查公开 MCP 工具合同、官方 OpenAPI 目录及实际响应：

- `get_asin_variations`：取得父体、当前子体集合及属性。
- `get_asin_order_trends`：输入单个ASIN、站点、开始月及结束月，返回 `trends[{date, orders}]`。
- 官方月订单接口为 `/v1/asins/orders/trends`，公开参数为 `asin`、`country`、`startMonth`、`endMonth`；未发现父体聚合开关或父体份额字段。
- LEPOWER与OYEARS样本直接查询父ASIN均返回0，子体有非零记录。这不是“父体没有订单”的证据。
- 样本可返回2025-09至2026-08的12个月记录；不保证任意商品都有同等历史覆盖。
- 用户提供的LEPOWER近30天截图与一次批量MCP查询对应：300、100、50、0；正值合计450，份额66.67%、22.22%、11.11%、0%。网页将最后一个子体显示为 `<50`。
- 西柚说明订单量来自亚马逊前台外显数据；接口0还可能涉及未披露或数据覆盖，不能普遍解释为真实0或确定的 `<50`。

方案比较：

1. 官方父体聚合接口：用户首选，但当前未取得可验证合同，不虚构接口或额外参数。
2. 西柚子体订单汇总：用户已允许，作为本版可实施方案；清楚标注数据来源与计算口径。
3. 抓取网页内部接口：不纳入本版，避免绑定浏览器登录态或未承诺稳定的内部协议。

本版采用方案2。以后如获得方案1，需验证周期、父子体范围及字段语义，再独立变更；本次不搭建通用供应商切换框架，也不重复调用已返回0的父ASIN试探接口。

## 3. 固定12个月统计口径

- 使用最近12个完整自然月。2026年9月运行时，窗口为2025-09至2026-08；不纳入未结束的2026年9月。
- 以采集开始时的UTC年月固定窗口；同批次所有父子体使用同一窗口，跨月完成也不混合周期，开发机和服务器时区不会改变计算结果。
- 范围严格为当前西柚变体关系识别出的子体集合。界面注明“按当前变体关系汇总”，不声称恢复了历史拆分、合并或移出变体。
- 每个子体的年度汇总是该窗口内接口返回的月度订单值之和；父体展示值是所有唯一子ASIN年度汇总之和。
- 年度份额按“该子体年度汇总 / 同父体全部子体年度汇总”计算。不是月份额的算术平均，也不是最近一个月份额。
- 预览只显示3个子体时，分母仍包含全部已识别子体；不会将预览三项重新缩放到100%。
- 数值使用“西柚订单量汇总”与来源说明，不称为精确成交单量或销量件数。可见订单值为档位口径，保留 `+` 提示；份额标注为“已披露订单量份额（子体汇总）”。
- 全站其他模块原有的近30天销量、流量、VOC或报告口径不在本次变更范围内。

### 缺失与0值

- 分离“接口已返回该月份”与“该月份有可披露订单量”两个状态，响应覆盖12/12不等于精确订单全量可见。
- 保留原始0值及其来源状态。聚合时它不增加已披露订单值，但用户界面不将其描述为真实零订单。
- 未提供明确阈值的原始0显示“未披露”，说明“可能不足50或数据不可用”；不硬编码所有0为 `<50`。
- 若一个子体全年没有正值，不显示真实份额为0%的断言；表格显示“未披露”，并从有值部分的份额条中省略它，披露数量另行提示。
- 缺少月份、单子体请求失败、身份不符或格式异常，不补0、不外推成年数据。保留可用明细，标注“数据不完整”；该家族不输出完整年度份额条、年度排名结论或完整父体总量。
- 缺月或请求失败的子体，年度数值列显示“—”；可用月份仍可在详情查看，不把部分月份的合计放入年度列或年度排序。
- 缺失状态与原始0不同：12个月均有合法响应但包含原始0，可以展示已披露值汇总和其占比，同时显示未披露月份数量及统计口径。
- 所有子体均无正值或分母为0时，展示“暂无可披露订单数据”，不绘制100%份额或产生NaN。

## 4. 页面结构

标题：“父体订单量份额与12个月趋势”。

顶部直接显示“近12个完整月 · YYYY-MM—YYYY-MM · 西柚洞察 · 子体汇总”，不需要进入详情才能知道统计周期。

- 桌面端为双列竞品卡片，窄屏单列；保持用户输入竞品顺序及同父体合并规则。
- 卡片头保留主图、品牌、父ASIN、命中ASIN与子体数量；ASIN为普通Amazon跳转链接，不触发自动化浏览器。
- 主要区域展示12个月订单汇总、年度份额横条、数据覆盖和未披露提示。
- 表格列：变体/ASIN、12个月订单量、年度份额、当前价格、上架时间。当前价格明确为快照，不冒充年度均价；没有上架日期时仍显示“未提供”。
- 默认按年度已披露订单量降序预览3个子体，未知值置后，同值按ASIN稳定排序。保留查看全部入口。
- 点击“查看全部子体与月度趋势”后打开该竞品的详情窗口，关闭后回到卡片；默认页面不常驻原型图下方的“展开详情示意”区域。
- 全部子体详情中展示相同12个月的月度堆叠柱状图及对应数值；月份缺失显示缺口，不画零值柱。图例、表格和数据始终以ASIN绑定，不按返回顺序或颜色绑定。
- 保留独立的来源更新时间、采集时间、缓存标识和中文失败说明。
- 本版不新增近30天查询入口、自定义日期、颜色聚合切换或单独的AI调用；这些不属于跑通当前需求的必要项。

## 5. 数据流与隔离边界

沿用已存在的西柚服务端采集与授权runtime读取路径，不从浏览器、页面渲染或GET读取动作调用西柚。

1. 变体采集/缓存提供经过校验的父体与唯一子ASIN集合。
2. 新的订单采集模块对这些子体调用月订单趋势，按国家、子ASIN、起止月份去重。
3. 新的纯聚合函数只接受校验后的固定窗口记录，生成月度与年度展示结果、覆盖状态和份额。
4. 订单快照使用独立版本化合同及缓存目录 `AGENT_DATA_ROOT/xydc-orders/`，不改变旧变体缓存合同，不写 `app/*.ts` 生成数据。
5. 父体快照绑定国家、父ASIN、完整子体集合标识、窗口及版本。读取侧验证这些身份后，才与当前变体快照合并呈现。
6. 旧缓存没有订单数据时仍正常展示商品与变体信息，并提示订单数据待采集；不能把旧变体缓存的“新鲜”状态视为订单历史已齐全。
7. 继续采用原子缓存写入和已授权项目ASIN过滤。请求失败可保留同身份、同窗口的已验证旧快照，但必须标注缓存/失败状态，不能拼接不同周期或不同子体集合。

采集继续为非阻断的西柚补充阶段，不改变VOC、鉴权、核心同步任务成功条件。增加工具白名单时只开放本次实际需要的月订单趋势工具；认证只在服务端使用，凭证不得进入前端、日志、Git或快照。

历史请求顺序执行，相邻请求开始时间至少间隔2秒；去重和24小时有效缓存优先。单次请求上限15秒，订单采集阶段总上限300秒，外层任务取消优先生效。429仅在供应商等待提示不超过30秒且本阶段剩余时间足够时重试一次；其他失败留待下一次同步补齐，认证/额度错误停止本轮后续历史调用。月份变化必须使用新窗口，部分失败只补缺失项。预算耗尽时明确标注未采集子体，不得只取前3个子体却标记为全量成功。
