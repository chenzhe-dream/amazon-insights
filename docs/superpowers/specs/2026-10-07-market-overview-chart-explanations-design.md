# 市场总览图表说明与业务总结展示设计

## 目标

市场总览报告只在图表附近展示用户可执行的业务解释。删除技术口径、指标引用和来源边界等实现备注，保留采集失败、缺失和趋势缺口等会影响判断的提示；所有原版章节的业务总结直接可见。

## 展示规则

- 行业销售趋势及其他图表不再显示“按原版展示……”“月度数字与指标引用”“来源与分母”等技术说明。
- 采集失败、尚未采集、来源为空、部分数据可用、趋势缺口等提示继续保留。
- 每个原版章节渲染一个展开的“业务解释”卡片，包含“数据表现、数据含义、业务结论”。
- 章节解释优先使用 `chapterSynthesis.chapters`，回退到 `originalSynthesis.chapters`；均不存在时显示明确的“当前报告暂无可用业务总结”，不留空白。
- 不改变 Sorftime 数据采集、保存、计算、评分及报告合同。

## 组件边界

`market-overview-reference-sections.tsx` 负责章节编排、销售趋势和商品集中度的技术说明清理，以及章节总结的可见渲染；`market-overview-distributions.tsx`、`market-overview-demand-trend.tsx`、`market-overview-product-demand.tsx` 清理各自图表的技术备注；`market-ui-reference.css` 提供业务总结卡样式。

## 验收

- 渲染行业销售趋势时不包含原版 Sorftime 口径文案和“月度数字与指标引用”。
- 渲染有章节数据的报告时，销售趋势、品牌集中度、价格分布等章节的“业务解释 / 数据表现 / 数据含义 / 业务结论”直接出现在 HTML 中。
- 没有章节数据时显示明确占位语句。
- 失败、缺失和趋势缺口提示仍存在。
- 现有市场总览原版图表和布局测试继续通过。
