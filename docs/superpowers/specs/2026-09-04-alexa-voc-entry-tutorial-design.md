# Alexa VOC 录入教程弹窗设计

日期：2026-09-04

状态：用户已确认弹窗与模板增强方案，等待规格复核

## 1. 目标

在“竞品 VOC 汇总”页面的“Alexa 七问 · 快速录入”区域增加一个轻量的“查看录入教程”入口。用户点击后，无需离开当前页面即可查看 Alexa for Shopping 的实际操作截图、三步录入说明和可直接复制的七问模板，降低第一次使用时不知道从哪里提问、复制什么内容的理解成本。

本次只增加前端帮助能力，不改变 VOC 导入、ASIN 绑定、标准化、分析任务、数据库或权限逻辑。

## 2. 已选交互

在“Alexa 七问 · 快速录入”标题附近放置一个带信息图标的小型描边按钮：

`ⓘ 查看录入教程`

点击后打开居中的模态弹窗。弹窗使用双栏布局：

- 左栏展示三步操作说明、强调提示和七问模板。
- 右栏展示用户提供的 Alexa for Shopping 实际操作截图。
- 页面背景增加半透明遮罩，但保留当前 VOC 页面上下文。

桌面端优先双栏；窄屏下改为单栏，步骤在上、截图在下。

## 3. 教程内容

标题：`Alexa VOC 录入教程`

固定步骤：

1. 打开 Amazon 商品详情页与 Alexa for Shopping。
2. 将七问模板一次性粘贴到对话框。
3. 复制 Alexa 完整回复，返回系统选择对应 ASIN 并导入。

强调提示：`请复制完整回复，不要只复制摘要。`

七问模板标题：`七问模板`

固定模板全文：

`这个产品的顾客关注点是什么、好评点是什么、差评点是什么、未被满足的需求是什么、使用人群是谁、使用场景是什么、购买动机是什么。`

模板使用只读文本框完整展示，允许用户手动选择文字。右上角提供“复制模板”按钮：复制成功后短暂显示“已复制”；若浏览器剪贴板能力不可用，则选中文本并尝试浏览器复制兼容路径；仍失败时显示“复制失败，请手动选择”。复制状态只存在于当前弹窗，不写入服务端。

截图使用用户在 2026-09-04 提供的 Alexa for Shopping 页面截图。实施时把原图原样复制为项目静态资源；不使用 AI 生成图替代，不裁掉底部七问输入区域。以后可以直接替换同一路径图片，不需要修改组件代码。

## 4. 组件与文件边界

为减少与并行 OpenSpec 开发的冲突，本功能保持独立：

- 新增教程弹窗组件，独立管理打开、关闭和键盘行为。
- 七问模板和复制状态保留在该教程组件内部，不新增全局状态或 API。
- 新增组件级样式文件，避免继续堆叠全局 CSS。
- 新增一张 `public` 下的教程截图资源。
- 仅在 `app/alexa-voc-import-panel.tsx` 增加教程入口和组件挂载点。
- 不修改 `app/page.tsx`、VOC 数据模型、服务端路由、OpenSpec 文件或任何运行时生成数据。

开发在独立 `codex/` 功能分支和 worktree 中完成。开始实施前、合并前都重新检查 OpenSpec worktree 的脏文件；发现相同文件被并行修改时停止合并并先做人工协调，不覆盖对方改动。

## 5. 弹窗行为与无障碍

- 点击“查看录入教程”打开弹窗。
- 点击右上角关闭按钮关闭。
- 按 `Escape` 关闭。
- 点击遮罩空白处关闭；点击弹窗内容不关闭。
- 弹窗打开后把焦点移到关闭按钮。
- 关闭后把焦点还给教程入口按钮。
- 使用 `role="dialog"`、`aria-modal="true"` 和明确的可访问名称。
- 截图提供描述性 `alt` 文本。
- 弹窗打开时阻止背景页面滚动；卸载或关闭时恢复原状态。

## 6. 视觉规则

- 沿用当前系统的白色卡片、蓝色强调色、圆角与阴影，不引入新的设计体系。
- 入口按钮保持次级操作视觉，不与“解析并写入 VOC 矩阵”主按钮争夺注意力。
- 弹窗最大宽度适配桌面页面，截图完整显示并允许在空间不足时等比缩小。
- 教程截图必须保持原始宽高比，不拉伸、不重绘文字。

原型图仅用于确认布局；最终界面由确定性的 React/CSS 实现，实际截图使用用户原图。

## 7. 错误与降级

该功能不发起网络请求，因此没有加载状态。

- 图片资源加载失败时仍显示三步文字说明、七问模板与图片替代文本。
- 剪贴板写入失败时保留可选中的只读模板，并显示“复制失败，请手动选择”。
- JavaScript 可用时提供完整模态交互。
- 教程功能自身异常不得影响 VOC 文本输入和导入按钮。

## 8. 测试与验收

自动化测试覆盖：

- 页面存在“查看录入教程”入口。
- 点击后出现名称为“Alexa VOC 录入教程”的模态弹窗。
- 弹窗包含三步固定文案、强调提示、正确图片路径和替代文本。
- 弹窗完整显示固定七问模板。
- 点击“复制模板”把模板全文写入剪贴板并显示成功反馈。
- 剪贴板失败时显示失败反馈，且只读文本仍可手动选择。
- 关闭按钮、遮罩和 `Escape` 均可关闭。
- 打开与关闭后的焦点位置正确。
- 弹窗关闭后不残留背景滚动锁。
- 现有 Alexa VOC 导入组件测试保持通过。
- 目标 ESLint 和生产构建通过。

人工验收：

1. 打开 VOC 页面，确认教程入口在快速录入标题附近且不抢主按钮视觉。
2. 打开弹窗，确认三步说明、七问模板清晰，用户原始截图完整显示。
3. 点击“复制模板”，粘贴到临时文本框并确认全文一致。
4. 分别使用关闭按钮、遮罩和 `Escape` 关闭。
5. 缩小浏览器宽度，确认内容改为单栏且无横向溢出。
6. 正常粘贴并导入一份 Alexa 报告，确认教程功能没有影响原流程。

## 9. 非目标

- 不制作多页轮播教程。
- 不增加视频或远程图片托管。
- 不记录用户是否看过教程。
- 不自动打开教程。
- 不允许用户在教程弹窗内编辑或保存七问模板。
- 不修改 VOC 导入解析规则。
- 不在本次工作中合并或重写 OpenSpec 并行分支。
