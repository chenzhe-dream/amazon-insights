# 市场四模块独立查询输入设计

## 决定

市场总览、商品形态及价格带、类目关键词洞察、类目买家评论见解各自拥有站点、类目节点及研究月份的查询草稿。修改或重置一个模块的草稿不改变其他模块，也不启动其他模块任务。四模块联动及自动填充另行设计，本次不实现。

现有模块采集、规则、人工修订和已保存报告不变。查询草稿与已保存任务的范围分开：切换模块或修改草稿不修改任务和报告，恢复报告只读取已保存数据。

## 状态和兼容性

- 总览继续使用现有 `marketSite`、`marketNode`、`marketFrom`、`marketMonth` URL 参数及收藏格式。
- 其他三模块各使用独立的 URL 参数存放站点、节点和月份。导航保留全部四模块参数；刷新页面恢复各自草稿。
- 旧的单模块深链或收藏仍可使用通用 `market*` 参数初始化其目标模块，但不应覆盖总览或另外两个模块。新导航为未填写的目标模块写入空节点标记，避免把总览节点误当成目标模块的输入。
- 团队收藏仍按当前模块的查询范围保存；恢复收藏只更新收藏所属模块。已保存任务 ID 可随模块导航保留，访问报告不重新采集。

## 验收

依次在总览、形态、关键词、评论模块输入四个不同节点，往返切换及刷新后各值不变；修改站点和月份也互不影响。每个模块单独提交时仅以本模块范围创建任务。旧链接与收藏可恢复，切换或恢复不触发采集。桌面和窄屏入口检查样式、空态及报告入口。
