# 类目买家评论见解规则版收口

## 已确认的范围

第四模块继续独立输入类目节点。新建任务只采集冻结商品池及各 ASIN 的 Amazon Customers Say 聚合主题，按本地规则计算主题提及次数、正负计数、商品内与跨商品份额，保存一份可重读报告。此阶段不运行 Agent，也不把主题摘要说成逐条评论或独立评论数；来源失败、空样本和未取得字段保持原状态。

## 版本与历史

新建任务使用 `market-theme-flow/rules-v2`，成功报告使用 `market-theme-report/v3`。这两个版本只改变规则报告的完成口径：没有运行模型不构成模型失败；来源覆盖完整时显示规则数据完整，来源缺口仍显示部分或无数据。`rules-v1` 及历史语义流程继续按保存时的报告口径重放，避免报告哈希不一致。

样本排除、恢复会基于冻结来源重算，并保存不可变修订；规则版新修订使用 `market-theme-selection-revision/v2`。读取时同时校验旧 v1 与新 v2 修订，不改写历史修订。历史 v1 规则修订的存储状态保持原值，界面依其冻结来源覆盖展示规则状态。

## 页面与验收

保留现有查询卡片、正负见解、样本表、报告详情及历史入口。规则版显示原主题、提及分母、来源摘要和“语义归组未启用”，不显示模型成员为零、模型结果缺失或等待模型。历史语义报告继续显示其原有归组与证据。

隔离 PostgreSQL 验收从创建任务、来源采集、规则报告、主题明细到样本修订和重放；浏览器验收桌面与窄屏的已保存报告、摘要来源及只读刷新。供应商真实数据、三模块分别验收与连贯测试留待用户验收阶段；正式服务不在本次任务发布。
