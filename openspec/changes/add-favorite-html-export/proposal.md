## 当前增量：导航式多页面快照（2026-09-27，已批准实施）

原页面长页快照已于 f4646fd6 发布。本次按用户指定的应用左侧导航组织一个 HTML 文件：六个一级入口、十个内容页面，包含 VOC 三个子页面、关键词两个子页面及竞品概览两个子页面，移除市场调研、收藏夹及管理入口。变体 / 订单保持在竞品参数总览内，并保留其内容选择项。预览和下载同一导航结构，页面切换不请求新数据。

用户理解父子勾选后已批准按计划实施；本轮不授权正式发布。详细导航映射、接口和六阶段任务见 `docs/superpowers/plans/2026-09-27-snapshot-navigation-pages.md`。现有八种数据来源、安全校验、固定正文及原页面内容继续复用，不扩大到分析规则或后端改造。以下是已完成阶段的原始说明。

## Why

业务需要下载一个 HTML 快照，固定分享时的报告内容，避免线上继续修改影响已发送的版本。用户已明确不要求离线图片，也不需要服务端导出任务和文件管理。2026-09-26 用户验收发现，现有实现把底层字段、证据对象与重复规则展开为超长报告，偏离原页面快照。此次按已确认的方向修订计划：直接保留原模块的页面呈现，先做计划，再逐模块实施。

## What Changes

- 保留一期已实现的收藏行「导出」、悬浮窗、模块勾选和可见范围过滤。
- 读取所选模块的已有页面来源并冻结，复用原页面共享展示组件，再捕获业务区域 DOM 与真实样式；预览与下载使用同一份 HTML。
- 保留原页面的表格、卡片、图表、配色与可展开详情；分页和懒加载的已有业务记录完整可读，不把底层对象递归铺成字段长表。
- 不额外附加原页面未显示的历史报告、内部引用、规则库与原始错误代码；缺口用对应业务位置的中文提示。原页面运营可查看的依据/规则仍可折叠展开。
- 浏览器直接下载，取消原二期的服务端快照创建、生成队列、轮询、文件存储、过期清理和离线图片打包。
- 优先复用既有已发布报告版本与只读结果接口；必要时只补原读取链路缺失字段，不新增分析、供应商调用或数据迁移。
- 区分未生成、已有缺失和读取失败；不填零、不自动补分析、不悄悄遗漏已选模块。
- 收藏仅保存入口，不冻结业务数据；预览准备时固定已有页面来源，之后下载同一份 HTML。变体/订单按已获授权的项目范围读取页面共享缓存，标明来源和时间，不冒充已发布分析批次。
- 实施限定导出适配与必要只读校验，不合并其他窗口，不自动发布。
