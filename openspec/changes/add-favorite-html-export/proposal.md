## Why

业务需要把收藏项目发给他人，并保留发送时的完整分析版本；现有收藏只是项目标记，线上内容会继续变化。用户已确认先实现前端收藏行导出入口和悬浮预览，随后接入后端。

## What Changes

- 第一期：已收藏分析项目行新增「导出」，打开模态悬浮预览；模块勾选、项目摘要、关闭返回和无后端状态可验收。
- 第一期只展示导出范围与真实项目元信息，不展示虚构分析结果、完成状态或模拟下载；后端未接入时确认导出禁用。
- 第二期：后端固定完整项目数据与素材，预览和 HTML 使用同一快照和模板，提供生成状态与鉴权下载。
- 保留现有收藏、编辑、加载与分析规则，不改其他工作窗口，不自动发布。

## Capabilities

### New Capabilities
- `favorite-html-export`: 收藏前置的模块化导出预览与固定 HTML 报告，包含明确的前后端分期。

### Modified Capabilities
无。

## Impact

第一期仅影响 app/project-library-panel.tsx、app/page.tsx 的可见模块传递、独立预览组件和浏览器回归测试。第二期新增导出服务与模块适配器；不迁移原业务数据源，不调用模型，不改变正式 runtime/data 根目录。
