## Context
orderColorMap 当前只按 ASIN 排序轮用八种色，card/detail 共用；xydcVariantAttributeLabel 用少量手写中译表。来源仅有 dimension/value/labelZh，没有独立色码。不得从非颜色属性或父体图片猜子体颜色。
## Decisions
1. 固定 meodai/color-names 的提交版本与 MIT 许可，本地持有名称→色码；更新脚本验证输入，记录来源、版本和摘要。运行时无网络。
2. 基础色/明确十六进制/精确字典匹配优先；明确双色连接符可组成分色示意，不表示实物配色面积。仅能识别基础色词时回退近似色；无可识别信号则中性纹理。中文基础色系用于近似标签，不伪装冷门名称的逐字翻译。
3. 确切中文名称优先来源 labelZh，再用既有词表。缺少中译时输出近似色系及原文。颜色属性以外的尺寸、形状、型号保留原逻辑。业务未配置普通翻译服务时不调用收费接口；用户选择接入时另补明确的配置/缓存边界。
4. 所有视图按 ASIN 读取同一颜色解析结果；同色子体不合并，排序不改色；新增子体不改其他子体颜色。未知子体不借用兄弟颜色。
5. 单色百分比黑/白文字按对比度选择；双色标签加底色；浅色圆点和条段有边框，相邻同色有分隔。名称/ASIN/数字仍可独立识别。
## Risks
通用色名库只能近似实物颜色，营销色名和印花无法保证准确。界面明确色块为示意，近似名称保留原文。完整词典有体积成本，测量压缩体积，不增加运行时 API 开销。
## Validation
覆盖 Aqua Blue、Blue、Orange、Lime Green、Black-Red、浅色/透明、陌生名称、基础词近似、误拼无信号、同色不同大小、非颜色维度；属性顺序与 ASIN 集合变化保持配色；所有原统计不变。真实组件浏览器测试验证卡片/月度/图例一致、点击悬浮行为和可读性。
