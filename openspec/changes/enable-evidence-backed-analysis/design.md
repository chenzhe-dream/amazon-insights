## Context
沿用第一期共享证据校验和三个现有页面。现有手工 VOC 以标准化原文提供，评论指标有两种不同口径；搜索量不可作为产品规格或评论频率。

## Goals / Non-Goals
接入现有输入，在有证据处恢复判断和需求排序。保留商业评分缺项状态；不增加采集、数据库迁移、模型调用或完整 VOC 扩展。

## Decisions
- 证据适配保留 ASIN、来源、维度、原文、真实采集时间和指标口径。时间缺失明确显示未提供，不以计算时间代替。记录 ASIN 不匹配或未就绪不进入证据。
- 有限同义替换只包含高度可调、亮度可调等明确等价短语；仍需原句支持，不做模糊相似度放行。消费者愿望和工程建议可作为候选，不能证明产品已有功能。否定、条件和跨 ASIN 校验继续执行。
- 原始负评/未满足需求按明确主题标签归组；每个 ASIN 只计一次反馈覆盖。按覆盖竞品数降序；覆盖相同且两项拥有同一组 ASIN、采集时间、分母和评论样本口径时，以样本提及率作辅助排序；其余保留稳定顺序。排名不是 P0/P1 商业优先级。
- 评论样本仅接收明确 review_sample_incidence 且合法分子分母；Customers Says 权重单列，不换算人数。关键词仅作为搜索信号列示，不参与需求覆盖或规格证明。
- 扩展现有分析依据区域显示需求排序及逐条原文，直接消费者复用共享结论校验。服务端只有验证主题而无规格输入时继续保守判断。

## Risks / Trade-offs
- 主题同义覆盖有限 → 保留原文候选，不扩大到全类目词库。
- 现有历史数据缺少采集时间或样本 → 显示缺项，禁止补默认值。
- 标准化 VOC 不是逐条评论 → 标识为手工 VOC 原文，不伪称买家逐字引文。

## Migration Plan
先用定向回归验证雪地产品与融蜡灯，再类型检查和受控发布。重算当前页面，无存档改写；如需回退仅回退本期改动，不回退共享工作区其他任务。
