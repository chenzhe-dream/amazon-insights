- 原有任务保留冻结的 flow、身份、来源与历史，不自动升级或重新付费；同一命令重复提交仍返回原任务。
- 以本地合成来源与模型验证从公开入口到综合报告的完整链，覆盖失败、缺失、版本不匹配和重试。

- 延续正式凭据与 API / MCP 调用，不引入 Cursor 进程、个人配置或前端业务计算。
- 将已验证的命令重放保护扩展至形态、关键词与评论模块；补齐冻结来源能够支撑的数据展示与规则说明，并完成四模块定向验收。具体模块补齐以原版与现有输入审计结果更新设计和任务，不自动恢复无证据评分。
