## Context
第二期按原始主题字符串归组。真实资料有灯泡寿命极短/灯泡寿命问题、尺寸偏小/尺寸太小、性价比争议/性价比有争议等明确等价表述。短标签可能缺少对象、条件或否定，不能采用模糊相似度通配。

## Goals / Non-Goals
只优化需求层的归组、计数、排序和解释；规格事实校验仍使用已有独立证据策略。不开启完整 VOC 扩展，不添加通用语义模型或全类目分类库。

## Decisions
- 归组规则独立于规格证明。仅对明确差评使用精确的有限别名表：灯泡寿命问题、尺寸偏小、性价比争议、耐久性差。未知标签继续保留，不做包含词/模糊匹配。
- 分组键包含维度、意图和规范主题；含适用限制、条件或待验证措辞的原文额外作为边界，避免消除条件。对消费者愿望不套用差评别名。
- 返回稳定分组 ID、原始主题列表和归并说明，原始证据不修改。UI 以 ID 渲染，展示差评/愿望及原始表述。
- 同 ASIN 覆盖只计一次。合并后同 ASIN 出现多个不同评论证据行，无法证明样本不重叠时不求和，即使分子分母数值恰好相同也不视为同一评论集；只有同证据 ID 的重复输入可去重。
- 原有覆盖及可比样本规则保持；最终平局按稳定分组键的码点顺序排序，不依赖来源返回顺序。证据 ID 与原始表述列表同样稳定排序。

## Risks / Trade-offs
- 精确规则覆盖有限 → 通过雪地产品和融蜡灯的实证逐条扩充，未知保持分开。
- 别名归并后样本重叠不明 → 显示原因并保持样本率为空，不凭计数相同推断可合并。
- 同类需求存在不同严重程度 → 规范主题只表示问题类别，原文保留严重程度，不输出统一严重性评分。

## Migration Plan
定向回归与真实数据库只读核对完成后受控发布。无迁移或存档改写；仅当前计算结果重新归组。回退只处理第三期文件改动，保留共享工作区其他任务。
