## Context
原 canView 同时用于统计读取与模块配置。历史无配置用户默认全部模块可见，不能从 admin-users 勾选推导授权。
## Goals / Non-Goals
目标：明确授权普通用户读取本组织统计，前后端一致；授权不扩大为管理权。
非目标：角色系统重构、部门范围、真实人员批量授权、正式发布。
## Decisions
- 在 user_module_visibility 增加 statistics_view_granted 布尔字段，迁移默认 false，无历史回填。复用目标行锁、version 与审计事务。
- 单人配置显示独立授权复选框，授权时同时选中统计模块；取消模块时取消明确授权。批量模块配置不修改授权，需逐人明确授权；默认设置接口拒绝授权字段。
- 个人保存新增可选 statisticsViewGranted；省略保留原授权，兼容旧客户端。授权 true 要求模块包含 admin-users。
- 新读取权限为：已有合法查看资格，或当前账号有效、同组织、明确授权且模块可见。每次接口访问重新读取，失败关闭。
- 模块管理继续使用原资格判定，绝不调用扩展后的统计读取判定。
- 保留所有者及原指定人员资格；界面说明独立开关不撤销既有系统授权。新授权不会修改角色。
- 保存后提示目标用户刷新；后端撤权立即生效，旧页面请求遇 403 不能继续读取。
## Risks / Trade-offs
需先迁移再启动新版服务。默认值 false 防止意外批量授权。原合法查看者的撤权仍由既有系统管理机制处理，本次开关仅管理明确授权。
