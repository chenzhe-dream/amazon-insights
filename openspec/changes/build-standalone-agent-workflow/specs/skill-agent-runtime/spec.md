## Purpose

定义一个不依赖 Codex、Cursor 或当前对话上下文的 Skill 智能体运行契约，使仓库内的分析规则能够被版本化加载、稳定执行、校验和审计。

## ADDED Requirements

### Requirement: 从版本化 Skill 定义创建智能体
系统 SHALL 从随应用发布的版本化 Skill 定义中读取目标、规则、引用资料和输出约束，并以明确的 Skill 标识和版本执行。

#### Scenario: 加载已注册 Skill
- **WHEN** 编排器请求一个已注册的 Skill 标识和版本
- **THEN** 运行时加载对应内容及必需引用文件，并返回可执行的智能体定义

#### Scenario: Skill 文件不完整
- **WHEN** Skill 缺少入口文件、必需引用或版本元数据
- **THEN** 运行时拒绝执行并返回配置错误，不使用隐式默认内容补齐

### Requirement: 不依赖宿主对话上下文
系统 SHALL 仅使用运行请求中声明的结构化输入、Skill 内容和服务端配置构造模型请求，不得依赖 Codex 会话、Cursor 规则或开发者机器上的隐藏上下文。

#### Scenario: 在普通服务器执行
- **WHEN** 同一版本应用在没有 Codex 和 Cursor 的服务器上获得相同输入与模型配置
- **THEN** 运行时能够创建并完成同一类智能体运行

### Requirement: 模型提供商可替换
系统 SHALL 通过统一模型接口执行智能体，并将模型提供商、模型标识和关键生成参数作为运行配置保存。

#### Scenario: 使用已配置模型提供商
- **WHEN** 服务端为智能体配置了可用的模型提供商和凭据
- **THEN** 运行时执行请求并记录不含秘密值的模型配置元数据

#### Scenario: 模型服务不可用
- **WHEN** 模型超时、限流或返回提供商错误
- **THEN** 运行时将尝试标记为失败或可重试，并返回标准化错误而不暴露 API Key

### Requirement: 结构化输入输出校验
系统 SHALL 在调用前校验智能体输入，在接收后校验智能体输出；不符合契约的结果不得作为成功报告发布。

#### Scenario: 输出通过校验
- **WHEN** 模型结果满足目标智能体的输出模式和必填字段
- **THEN** 系统保存规范化结构化结果并将运行标记为成功

#### Scenario: 输出格式错误
- **WHEN** 模型返回无法解析或缺少必填字段的结果
- **THEN** 系统保存原始响应的受控诊断信息，并执行有限修复重试或将运行标记为失败

### Requirement: 运行可审计
系统 SHALL 为每次智能体尝试保存输入快照摘要、数据来源、Skill 版本、模型元数据、输出版本、开始结束时间和错误分类。

#### Scenario: 查看报告来源
- **WHEN** 用户或审核者查看一次智能体结果
- **THEN** 系统能够返回生成该结果的 Skill 版本、数据截止时间和模型标识

### Requirement: 模型调用预算与有限重试
系统 SHALL 对每次智能体调用、每次分析运行和组织每日用量执行管理员配置的硬上限，并且只对明确允许的错误执行有限重试。

#### Scenario: 暂时性提供商错误
- **WHEN** 模型提供商返回限流或暂时性服务错误且预算仍允许
- **THEN** 运行时按退避策略最多重试两次，并记录每次尝试

#### Scenario: 结构化输出可修复
- **WHEN** 模型首次输出无法通过模式校验但响应可以用于格式修复
- **THEN** 运行时最多发起一次受约束的修复请求，仍失败则终止该智能体运行

#### Scenario: 达到任务预算
- **WHEN** 新的模型请求会超过调用级、运行级或组织每日上限
- **THEN** 系统不得发送请求，并将阶段标记为 budget-exceeded 且显示已使用额度

#### Scenario: 查看模型用量
- **WHEN** admin 查看一次运行的模型使用情况
- **THEN** 系统返回各智能体的模型、输入输出 Token、耗时、重试次数和费用估算

### Requirement: 禁止无界智能体循环
系统 SHALL 只允许编排器按照声明的依赖图创建智能体运行，智能体输出不得直接递归启动自身或任意其他智能体。

#### Scenario: 智能体输出包含未授权后续调用
- **WHEN** 模型结果要求执行未在编排计划中声明的智能体或工具
- **THEN** 系统将其作为建议文本或校验错误处理，不自动执行该调用

### Requirement: 模型输入最小化
系统 MUST 按目标智能体的声明白名单构造模型输入，只发送完成当前分析必需的结构化业务数据，并禁止发送秘密、登录会话、用户身份和无关项目数据。

#### Scenario: 构造 VOC 智能体请求
- **WHEN** 运行时为 VOC 定位智能体准备模型输入
- **THEN** 请求只包含所需 ASIN、VOC 主题与指标、必要匿名证据、确定性结果、Skill 和输出模式

#### Scenario: 输入对象意外包含秘密字段
- **WHEN** 待发送对象包含 API Key、Cookie、密码、会话标识、请求授权头或成员身份字段
- **THEN** 运行时拒绝发送、记录脱敏安全事件并将运行标记为配置或安全错误

### Requirement: 模型日志默认不保存完整业务内容
系统 SHALL 默认只记录模型请求和响应的标识、模式版本、记录数量、摘要哈希、Token、耗时与错误分类，不得把完整提示词、评论全文或秘密写入普通日志。

#### Scenario: 模型调用成功
- **WHEN** 模型提供商返回有效响应
- **THEN** 普通运行日志记录调用元数据和使用量，而不记录完整输入与完整输出正文
