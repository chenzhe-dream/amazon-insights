## Purpose

定义可在本地与生产环境中持久运行的数据采集业务能力，把第三方连接器、人工输入和任务状态与短生命周期 Web 请求明确分离。

## ADDED Requirements

### Requirement: Web 请求与后台采集分离
系统 SHALL 由 vinext Web 通过 HTTP 请求 Node Agent Service 创建持久化采集任务，并由 Agent Service 的后台执行循环处理；vinext Web 不得直接打开本机数据库、派生脱离进程或依赖请求结束后的本机文件写入继续工作。

#### Scenario: 创建采集任务
- **WHEN** 用户要求补齐 ASIN 数据
- **THEN** Web API 返回任务标识，并可在原请求结束后继续查询任务进度

#### Scenario: 执行器暂不可用
- **WHEN** 没有可用后台执行器领取任务
- **THEN** 任务保持排队或失败为基础设施错误，而不是向用户返回已开始自动分析

### Requirement: 按数据模块公开状态
系统 SHALL 为每个 ASIN 分别记录商品底库、关键词、评论、销量、Listing、图片备注、流量和 VOC 等数据模块的状态、来源与更新时间。

#### Scenario: 部分模块已缓存
- **WHEN** 某些 ASIN 的部分模块已满足新鲜度要求
- **THEN** 系统复用这些模块，只为缺失或过期模块创建采集步骤

#### Scenario: 单一连接器失败
- **WHEN** 一个数据源连接器失败但其他模块已成功
- **THEN** 系统保留成功数据并清楚标记受影响的模块和下游分析

### Requirement: 连接器能力与凭据检查
系统 SHALL 在执行前检查连接器是否启用、凭据是否存在以及运行环境是否具备所需能力，并向用户返回可操作状态。

#### Scenario: 缺少第三方凭据
- **WHEN** 连接器未配置必要凭据
- **THEN** 对应阶段进入 waiting-input，并说明需要配置的凭据类别而不返回秘密值

#### Scenario: 需要交互式浏览器
- **WHEN** 数据源仅能通过已登录浏览器或人工导入获得
- **THEN** 系统不得在无浏览器的服务器上假装自动执行，而应提供受支持的采集器或人工导入路径

#### Scenario: MVP 缺少 Amazon VOC
- **WHEN** 当前运行缺少 Amazon/Alexa VOC 且尚未部署合规的浏览器采集器
- **THEN** VOC 阶段进入 waiting-input，并允许用户通过网页粘贴或文件导入补充数据

#### Scenario: 导入 VOC 后继续运行
- **WHEN** 用户为 waiting-input 阶段提交通过格式与 ASIN 校验的 VOC 数据
- **THEN** 系统保存带来源的快照，并恢复所有已满足依赖的后续分析阶段

### Requirement: MCP 连接器独立于开发工具
系统 SHALL 由后台 Worker 通过声明的远程地址和服务端秘密直接连接 MCP 服务，不得要求安装、启动或读取 Cursor、Codex 等开发工具的配置。

#### Scenario: 无 Cursor 的服务器运行 MCP
- **WHEN** 服务器未安装 Cursor，但已为目标连接器配置远程地址和有效服务端秘密
- **THEN** Worker 能够调用该 MCP 服务并记录不含秘密值的连接器元数据

#### Scenario: 仅存在 Cursor 配置
- **WHEN** 运行环境没有服务端秘密，只有开发者机器上的 Cursor 配置
- **THEN** 生产运行不得读取该配置，并将连接器标记为未配置

### Requirement: 采集数据具有来源记录
系统 SHALL 为采集结果保存数据源、站点、统计周期或抓取时间、原始记录引用和转换版本。

#### Scenario: 数据进入智能体输入
- **WHEN** 某数据模块被用于分析
- **THEN** 分析输入能够追溯到该模块的来源和时间信息

### Requirement: 秘密与会话安全
系统 MUST 将 API Key、第三方凭据和浏览器会话作为服务端秘密处理，不得写入客户端响应、源码仓库、普通日志或模型提示词。

#### Scenario: 连接器记录错误
- **WHEN** 第三方服务返回包含请求头或凭据片段的错误
- **THEN** 系统在持久化或展示前清理敏感信息

#### Scenario: 普通用户创建分析任务
- **WHEN** 非管理员用户提交 ASIN 并启动数据采集
- **THEN** 系统使用管理员预先配置的公司服务凭据，且不向该用户返回或要求输入秘密值

#### Scenario: 管理员轮换连接器密钥
- **WHEN** 管理员更新或吊销某个连接器的服务凭据
- **THEN** 系统记录不含秘密内容的审计事件，并让后续任务使用新配置
