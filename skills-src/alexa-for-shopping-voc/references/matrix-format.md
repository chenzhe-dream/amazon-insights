# 七维矩阵字符串格式规范

与 `app/rufus-voc-data.ts` 及 `scripts/lib/normalize-alexa-voc-sections.mjs` 对齐。

## 百分比与条数

```javascript
pct = (mentions / reviewCount) * 100
// ≥1% → 1 位小数，如 6.1
// <1% → 2 位小数，如 0.85
mentions 显示 → toLocaleString()，如 1,264
```

## 1. 顾客关注点 (`attention`)

**模板**

```
{序号}. {标题}：{详情}（{英文维度} {N} 条提及，约 {X}%）。
```

**示例**

```
1. 产品质量与耐用性：家长最关注车体是否扎实、能否长期陪伴孩子使用（Quality 1,264 条提及，约 6.1%）。
2. 安装难易度与上手体验：是否容易组装、孩子能否快速学会（Assembly 714 条提及，约 3.4%）。
```

**规则**

- 序号从 1 递增，最多 8 条
- 标题与详情用中文冒号 `：` 分隔
- 括号内：`{维度英文名} {条数} 条提及，约 {占比}%`
- 无统计数据时：`{序号}. {标题}：{详情}。`

## 2. 好评点 (`positives`)

**模板**

```
【{标签}】约 {X}% 评论提及（{N} 条）
```

**Mixed 变体**

```
【{标签}】约 {X}% 评论提及（Mixed，{N} 条）
```

**示例**

```
【质量与耐用性】约 6.1% 评论提及（1,264 条）
【组装轻松】约 3.4% 评论提及（714 条）
【LED 发光轮】约 2.2% 评论提及（457 条）
```

**规则**

- 最多 10 条
- 按 mention 占比或重要性降序

## 3. 差评点 (`negatives`)

**模板**

```
【{标签}】约 {X}% 评论提及（{N} 条）
```

**补充说明变体**（mention 分散、无法精确统计时）

```
【{标签}】{补充说明}
```

**示例**

```
【转向能力】约 1.5% 评论提及（306 条）
【尺寸与 lean 转向门槛】评论分散提及（2 岁偏大、需更大孩子才能独立转向）
```

**规则**

- 最多 8 条
- 区分产品问题 vs 物流/使用不当（后者一般不纳入矩阵，除非高频）

## 4. 未被满足的需求 (`unmet`)

**模板**

```
{序号}. {需求描述}。
```

**示例**

```
1. 希望 Lean-to-steer 转向更灵活，低龄儿童也能独立正常转弯。
2. 希望前轮/连接件材质更耐用，避免使用 1 个月左右即损坏。
3. 希望 LED 灯光效果更持久稳定，减少短期失效。
```

**规则**

- 以「希望…」开头优先
- 最多 8 条
- 来自 Alexa 归纳 + 评论证据，非主观臆造

## 5. 使用人群 (`audiences`)

**表头（必须有）**

```
人群分类｜特征
```

**数据行**

```
{人群分类}｜{特征描述 · 英文证据摘要}
```

**示例**

```
人群分类｜特征
幼儿 / 学龄前儿童（1–5 岁）｜Perfect size for young child · sit-stand 过渡
多年龄段儿童（含 5 岁+）｜4 档可调把手 · multiple ages
初学者 / 第一辆滑板车用户｜宽踏板 · 三轮稳定 · great first scooter
祖父母 / 礼物购买者｜Grandson / Granddaughter loves it · 生日礼物
```

## 6. 使用场景 (`scenarios`)

**表头（必须有）**

```
场景｜说明与示例
```

**数据行**

```
{场景名}｜{说明 · 典型评论场景}
```

**示例**

```
场景｜说明与示例
室内外日常骑行｜社区、车道、公园平路
第一辆滑板车入门训练｜sit-stand 二合一过渡
生日礼物 / 节日赠礼｜Verified Purchase 礼物评论高频
暗光环境展示型骑行｜LED 发光轮 · neighborhood
```

## 7. 核心购买动机 (`motives`)

**表头（必须有）**

```
动机｜重要性｜说明
```

**数据行**

```
{动机}｜{⭐ 星级 1–5}｜{维度 mention · 占比 · 补充}
```

**示例**

```
动机｜重要性｜说明
产品质量与耐用性｜⭐⭐⭐⭐⭐｜Quality 1,264 条 · 约 6.1%
易组装与易上手｜⭐⭐⭐⭐☆｜Assembly 714 · Ease of use 246
LED 发光轮与外观吸引力｜⭐⭐⭐⭐☆｜Lighting 457 · Appearance 305
适龄 / 第一辆滑板车｜⭐⭐⭐⭐☆｜Suitability for toddlers 503
性价比｜⭐⭐⭐☆☆｜Value for money 234
```

**规则**

- 重要性用 ⭐（1–5 个），可带 ☆ 表示半级
- 按决策影响力排序

## 报告页眉 (`alexaReport`)

| 字段 | 值 |
|------|-----|
| title | `顾客评价深度分析` |
| prompt | 固定七问 prompt（见 SKILL.md） |
| starBreakdown | 如 `5 星约 77% · 评论 2 万+（Alexa 对话框报告）` |
| overallConclusion | Alexa 8️⃣ 段或人工 1 段综合结论（≤600 字） |
| captureNote | `来源：Alexa for Shopping 对话框七问回复（日期）` |

## 待录入占位 (`pending`)

七维全部填：

```
待在 Alexa for Shopping 对话框提问七问后，按回复原文录入。
```

`captureStatus: "pending"`
