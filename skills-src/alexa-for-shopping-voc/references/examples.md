## 七维矩阵

### 顾客关注点

1. 产品质量与耐用性：家长最关注车体是否扎实、能否长期陪伴孩子使用（Quality 1,264 条提及，约 6.1%）。
2. 安装难易度与上手体验：是否容易组装、孩子能否快速学会（Assembly 714 条提及，约 3.4%）。
3. 适用年龄与「第一辆滑板车」定位：是否适合幼儿及 5 岁左右儿童（Suitability for toddlers 503 条提及，约 2.4%）。
4. LED 发光轮与外观吸引力：亮灯轮子与可爱造型是共同关注点（Lighting 457 条提及，约 2.2%）。
5. 转向 / Lean-to-steer 能力：前轮能否正常转弯是最大争议点（Turnability 306 条提及，约 1.5%）。

3. 希望 LED 灯光效果更持久稳定，减少短期失效。

## 输入 → 输出流程示例

**输入**：用户粘贴含 `1️⃣ 顾客关注点` … `7️⃣ 核心购买动机` 的 Alexa 全文。

**处理**：

1. 提取 ASIN `B0XXXX`、4.6 星、20856 评论
2. 按 emoji 分段
3. 每条主题行提取 label / dimension / mentions
4. 计算 pct，套模板
5. 输出七维矩阵 Markdown + 可选 TS 对象

**缺失处理**：若原文无 mention 统计，保留语义、占比标「暂无数据」，不编造条数。
