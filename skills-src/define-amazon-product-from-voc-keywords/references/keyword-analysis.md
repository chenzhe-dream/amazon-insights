## 1. 数据清洗

检查关键词重复、翻译偏差、空值、异常值、单位和时间口径。统一大小写、单复数、拼写变体和近义表达，但保留原始词。

将关键词分为：

- 高相关产品词；
- 相关需求词；
- 品牌/竞品词；
- 配件/兼容词；
- 错误相关或噪声词。

品牌词、竞品ASIN词和噪声词不进入产品需求规模计算。

不要直接相加包含关系或同义词的搜索量。例如“camping wagon”“folding camping wagon”“wagon for camping”可能属于同一词群；先建立去重词群，再呈现原始搜索量和估算边界。

## 2. 多标签分类

每个关键词允许多个标签：

| 一级维度 | 二级标签示例 | 产品定义用途 |
|---|---|---|
| 品类 | 核心品类、替代品、配件 | 确定市场边界 |
| 产品形态 | 折叠、充气、固定、壁挂、便携 | 确定结构路线 |
| 功能 | 基础、性能、便利、智能、安全 | 确定功能层级 |
| 属性 | 尺寸、容量、材质、颜色、风格 | 确定规格与SKU |
| 人群 | 成人、儿童、老人、宠物、专业用户 | 确定适配参数 |
| 年龄 | 婴幼儿、儿童、青少年、成人 | 转化安全和尺寸要求 |
| 身份/职业 | 家庭、露营者、运动者、技师 | 确定任务强度 |
| 场景 | 家庭、户外、旅行、办公室、车辆 | 确定环境要求 |
| 时间 | 季节、节日、活动 | 判断季节性和礼赠 |
| 痛点利益 | 省力、稳定、保暖、收纳、耐用 | 确定核心卖点 |
| 购买动机 | 礼物、DIY、定制、价格、品牌 | 确定版本与表达 |
| 搜索意图 | 了解、比较、评价、购买、兼容、问题 | 判断转化阶段 |

## 3. 需求规模

同时看：搜索量、购买量、购买率、点击量、ABA排名和相关度。

- 高搜索＋高购买：主流真实需求；
- 高搜索＋低购买：宽泛、比较型或错配风险；
- 中等搜索＋高购买率：精准高转化机会；
- 低搜索＋高相关＋高购买率：长尾细分机会；
- 高搜索＋低相关：不得进入产品定义核心。

有足够样本时使用同组分位数：P70以上为高，P30以下为低；用户已有阈值时优先使用用户阈值。样本不足时使用“本组领先/中等/靠后”，不制造精确分位。

需求规模结论必须基于去重词群，不使用单个大词代表整个市场。

## 4. 趋势与季节性

优先使用12至24个月数据：

- 长期与近期同时增长：成长需求；
- 长期稳定、近期增长：短期机会，验证事件驱动；
- 长期增长、近期回落：检查季节或竞争变化；
- 长期与近期同时下降：衰退风险；
- 单月峰值明显：季节性或活动型需求。

输出旺季起止、淡季起止、峰值月份、全年可售月份和波动风险。缺少完整周期时不得断言季节性。

## 5. 产品形态

统计不同产品形态词群的搜索量、购买量、趋势、价格带和供给数量，区分：

- 主流形态：需求大、购买稳定、供给成熟；
- 增长形态：规模中等但趋势和转化较好；
- 细分形态：需求小但人群/场景明确；
- 衰退形态：趋势下降或被替代；
- 伪机会：搜索量高但与目标产品不匹配。

最终只能选择一个主产品形态；其他形态作为变体、二代产品或不进入，避免把互相冲突的形态合并成一款产品。

## 6. 功能与性能

| 功能类型 | 判断依据 | 产品动作 |
|---|---|---|
| 基础必备 | 主流词群普遍出现，缺失会影响购买 | 标准配置，不作为唯一差异化 |
| 高关注 | 搜索规模或购买量高，影响比较决策 | 强化参数和页面表达 |
| 差异化 | 组合词增长、高转化、供给不足，并有VOC支持 | 优先验证并形成卖点 |
| 伪需求 | 低频、低相关、低转化或明显增加复杂度 | 首版不开发 |

性能词必须转成可验证参数或测试方向，不写“更强、更好、更耐用”等空泛描述。

## 7. 属性、规格与SKU

分别分析尺寸、容量、重量、承重、数量、材质、颜色、风格、结构和兼容性词群。

输出：

- 各属性需求占比；
- 搜索与购买表现；
- 竞争和价格差异；
- 主推规格；
- 辅助规格；
- 不建议开发的规格；
- SKU数量和变体逻辑。

不要仅凭颜色词搜索量扩充大量SKU；需结合购买量、转化、竞品销量和库存风险。

## 8. 人群与年龄

人群/年龄词必须转化为工程和体验要求：

| 关键词信号 | 需要转化的产品参数 |
|---|---|
| 儿童/年龄段 | 尺寸、承重、安全、夹伤、材料、操作难度 |
| 老年人 | 操作力、字体、稳定、防滑、安装和维护 |
| 成人/大码 | 尺寸、承重、人体工学、耐用性 |
| 专业用户 | 性能、寿命、效率、兼容、维护 |
| 旅行/移动人群 | 重量、折叠体积、便携、收纳、运输限制 |

只有人口标签、没有明确需求差异时，不单独定义产品版本。

## 9. 场景与购买动机

场景词转化为产品要求：

- 户外：防水、耐候、稳定、耐磨、续航；
- 旅行：重量、体积、折叠、收纳、运输；
- 家庭：安全、噪声、清洁、空间适配；
- 车辆：尺寸、固定、供电、收纳；
- 专业场景：性能、寿命、效率和兼容。

购买动机区分自用、礼物、DIY、定制、低价、品牌和替换。礼物词影响包装、外观和使用门槛，不自动证明高价格接受度。

## 10. 痛点与搜索意图

痛点词反映用户主动寻找解决方案，优先映射到VOC差评与未满足需求。

搜索意图区分：

- 信息了解：what、how、guide；
- 比较选择：best、vs、review；
- 购买决策：for sale、deal、buy；
- 兼容适配：for、compatible、replacement；
- 问题解决：easy、no leak、non slip、quiet；
- 组合需求：人群＋场景＋功能＋属性。

高搜索的信息词不等于高购买需求；高相关的购买和问题解决词更适合进入产品定义。

## 11. 竞争与供给

同时看搜索结果数、商品数、需供比、CPC、广告竞品数、点击/转化集中度、品牌/ASIN集中度、价格带、评分评论壁垒和新品表现。

- 高需求＋低供给＋中低集中：优先机会；
- 高需求＋高供给：升级机会，必须有差异化；
- 低需求＋低供给：长尾或低价值机会；
- 低需求＋高供给：不建议；
- 高CPC＋高集中：推广成本和头部壁垒风险；
- 新品有稳定购买份额：新品友好信号。

供给少不自动等于蓝海，可能由需求低、专利、合规、技术或利润限制导致。

## 12. 组合词机会

优先分析：

```text
人群 × 场景 × 功能 × 属性/规格
```

高价值组合词通常具备：高相关、购买率较高、趋势不差、供给不足、VOC有对应痛点或未满足需求。

输出每个机会词群对应的产品形态、功能、规格、人群、场景、价格带、竞争风险和可表达卖点。
