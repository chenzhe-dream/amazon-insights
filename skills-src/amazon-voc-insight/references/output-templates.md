## 7. 最终开品结论（必答清单）

1. 是否建议进入该类目或开发该产品？
2. 最推荐开发哪一个方向？
3. 应重点解决哪三个消费者痛点？
4. 应保留哪三个成熟卖点？
5. 哪些需求属于伪需求，不建议开发？
6. 产品应定位于哪个价格带和目标人群？
7. 新产品与头部竞品相比，核心差异化是什么？
8. 产品立项前还需要验证哪些数据？
9. 四选一结论：**优先立项** / **建议小批量测试** / **继续观察** / **暂不开发**

## 评分速查

维度（1–5）：需求频次、痛点强度、市场空间、竞品缺口、差异化程度、溢价能力、实现可行性（由实现难度/成本影响/合规风险正向转换）。

```
优先级分 = (需求×0.20 + 痛点×0.20 + 市场×0.15 + 缺口×0.15
          + 差异×0.15 + 溢价×0.10 + 可行性×0.05) × 20
```

| 得分 | 分档 |
|------|------|
| ≥80 | 优先立项 |
| 65–79 | 建议验证 |
| 50–64 | 谨慎开发 |
| <50 | 暂不建议开发 |
