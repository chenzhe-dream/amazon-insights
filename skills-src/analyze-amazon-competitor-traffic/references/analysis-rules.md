## 1. 计算公式

在原始数据未提供对应结果时计算：

```text
自然流量占比 = 自然流量 ÷ 总流量
广告流量占比 = 广告流量 ÷ 总流量
广告渠道占比 = 单个广告渠道流量 ÷ 广告总流量
子体流量占比 = 子体流量 ÷ 父ASIN总流量
推荐来源占比 = 单个推荐来源流量 ÷ 推荐专栏总流量
TOP1集中度 = 最大子体流量 ÷ 父ASIN总流量
TOP3集中度 = 前三个子体流量合计 ÷ 父ASIN总流量
HHI = 所有子体流量占比平方之和
```

将“父体内流量占比≥5%”的子体定义为有效子体。若用户另有口径，使用用户口径并说明。

百分比显示保留1位小数；数量可使用千、万等便于阅读的单位，同时保留关键原始值。

### 分母与标签校验

三类百分比不可混用：

- 父ASIN广告渠道分布：分母为父ASIN广告总流量；
- 子体堆叠条渠道分布：分母为该子体总流量；
- 推荐专栏来源分布：分母为推荐专栏总流量。

需要把子体广告渠道换算为“占子体广告流量”时，先用该子体各广告渠道流量或占比合计作为广告分母重新计算，并说明是换算值。

“SP推荐”是广告渠道，“推荐专栏”是推荐入口集合，不得因名称相近而合并。读取截图时使用数值所在行的实际文字标签；SB常规与SBV不得按颜色猜测。

## 2. 比较口径

优先在相同站点、相同或相近类目、相同统计周期内比较。

竞品数量达到5个时，优先使用同组分位数判断流量规模：

| 同组分位 | 流量规模等级 |
|---|---|
| ≥P80 | 5，头部 |
| P60～P80 | 4，中上 |
| P40～P60 | 3，中位 |
| P20～P40 | 2，中下 |
| ＜P20 | 1，尾部 |

竞品少于5个时，不制造精确分位排名，改用“本组领先/中等/靠后”，并提醒样本有限。

## 3. 父ASIN判断规则

### 3.1 自然流量占比

| 自然流量占比 | 初步判断 |
|---:|---|
| ≥75% | 自然沉淀突出 |
| 65%～75% | 结构健康 |
| 55%～65% | 自然与广告相对均衡 |
| 45%～55% | 广告依赖偏高 |
| ＜45% | 广告依赖明显 |

此表只给出初步判断，必须用自然流量绝对量修正：

- 总流量低于同组P20时，自然沉淀最高不得评为“强”；
- 总流量低于同组P10或明显低于其他竞品时，自然沉淀最高不得评为“中强”；
- 自然占比高但总流量很小，标记“低量自然型”或“比例假强”；
- 自然占比高、自然流量绝对量也处于同组前列，才可判断自然沉淀强。

### 3.2 广告强度

广告占比只表示付费流量介入程度：

| 广告流量占比 | 表述 |
|---:|---|
| ＜15% | 低广告介入 |
| 15%～30% | 适度广告维护 |
| 30%～45% | 积极推广 |
| 45%～60% | 广告强推 |
| ＞60% | 高度广告依赖 |

若广告绝对量很大且自然流量同步处于前列，可判断“付费拉量能力强”；若广告占比高但总量和自然量都弱，判断为“高投入依赖信号”，不得判断推广强。

### 3.3 广告渠道结构

将广告流量占比达到5%的渠道视为有效广告渠道。

| 有效渠道数 | 广告打法评价 |
|---:|---|
| 4个及以上 | 完整组合型 |
| 3个 | 多渠道型 |
| 2个 | 双渠道型 |
| 1个 | 单渠道型 |

修正规则：

- 任一广告渠道占广告流量≥80%，标记“渠道高度集中”；
- SP常规占比高，通常表述为关键词和商品投放主导；
- SP推荐占比高，通常表述为推荐位置或系统推荐流量利用较强；
- SB占比高，表述为品牌广告或品牌入口拉量明显；
- SBV占比≥10%，表述为视频广告已成为重要流量入口；
- 不推断具体预算、竞价或投放盈亏。

### 3.4 推荐专栏结构

同时比较推荐专栏绝对流量、同组排名和来源广度。将来源占比达到5%的入口视为有效推荐来源。

- 推荐流量绝对量领先且有效来源≥3：推荐渗透强；
- 绝对量中等且有效来源≥2：推荐渗透中等；
- 绝对量很小：即使来源占比分散，也不得判断推荐渗透强；
- 单一来源占比≥70%：标记推荐来源集中风险。

## 4. 子体判断规则

### 4.1 TOP1集中度

| TOP1占比 | 变体结构 |
|---:|---|
| ≥90% | 极端单爆款型 |
| 80%～90% | 单爆款驱动型 |
| 60%～80% | 主力子体主导型 |
| 40%～60% | 主力＋辅助子体型 |
| ＜40% | 多子体均衡型 |

### 4.2 TOP3集中度

| TOP3占比 | 判断 |
|---:|---|
| ＞85% | 高度集中 |
| 65%～85% | 中度集中 |
| ＜65% | 相对分散 |

TOP3集中度必须结合父体子体总数：若父体只有3个子体，TOP3为100%没有区分意义，应重点使用TOP1和有效子体数量。

### 4.3 有效子体

- 有效子体≥4且TOP1＜40%：矩阵能力强；
- 有效子体≥3且TOP1＜60%：矩阵能力中强；
- 有效子体≥2且TOP1＜80%：存在辅助承接；
- 有效子体≤1或TOP1≥90%：矩阵能力弱；
- 子体总数≥8但有效子体≤2：标记“变体虚胖”。

### 4.4 子体广告承接

分别比较主力与次主力子体：

- 主力子体广告占比高、次主力自然占比逐渐提高：可能处于“主推爆款带动辅助款”结构；
- 多个有效子体都有稳定自然流量：自然承接和矩阵能力较好；
- 广告集中于一个子体且TOP1≥80%：单爆款与广告双重依赖；
- 次主力子体广告占比高但流量绝对量仍小：辅助款尚未有效起量；
- 仅凭单期数据不得使用“逐渐提高”等趋势措辞，除非有多期数据。

## 5. 五维评级

使用“强 / 中强 / 中 / 中弱 / 弱”五档。只有同组数据口径可比时才做横向等级。

### 5.1 拉量能力

主要依据总流量同组位置，广告绝对量和推荐流量绝对量作为修正。总流量领先但来源单一，可保持拉量评级，同时在健康度中扣分。

### 5.2 自然沉淀

综合自然流量绝对量、自然占比和总流量规模。绝对量优先级不得低于占比。

### 5.3 广告打法

综合广告绝对量、有效渠道数量和渠道集中度。广告绝对量低时，多渠道占比不能单独支撑“强”。

### 5.4 推荐渗透

综合推荐流量绝对量、同组位置、有效来源数量和来源集中度。

### 5.5 变体运营

综合TOP1、TOP3、有效子体数量和多个子体的自然承接情况。

若用户要求100分制，可使用以下权重，但必须同时保留五维明细：

```text
综合推广能力 = 拉量能力30% + 自然沉淀25% + 广告打法15% + 推荐渗透15% + 变体运营15%
```

五档换算为5、4、3、2、1分。缺失两个及以上维度时，不计算总分。

## 6. 推广健康度

推广健康度不是拉量能力的同义词。依据以下信号综合判断：

### 健康信号

- 自然流量绝对量与占比同时处于较高水平；
- 至少2个广告渠道各占广告流量10%以上；
- 至少3个有效子体共同承接流量；
- 推荐流量绝对量不低且来源不少于3个；
- 主力子体之外，次主力子体也形成稳定自然流量。

### 风险信号

- 广告流量占比＞50%；
- TOP1占比≥80%，严重风险为≥90%；
- 单一广告渠道占比≥80%；
- 自然占比高但总流量处于尾部；
- 子体总数很多但有效子体≤2；
- 推荐流量单一来源占比≥70%；
- 父体流量大，但几乎全部集中于一个子体。

健康度结论使用“健康 / 基本健康 / 需观察 / 风险较高”，并列出触发信号。

## 7. 推广类型标签

每个竞品选择1个主标签，必要时加1个副标签：

| 标签 | 识别特征 |
|---|---|
| 成熟复合型 | 总流量领先、自然量与占比均强、渠道不单一、有效子体≥3 |
| 广告进攻型 | 广告绝对量大、广告占比30%～60%，自然沉淀尚未完全匹配 |
| 高度广告依赖型 | 广告占比＞60%或主力子体自然占比＜40% |
| SP关键词驱动型 | SP常规占广告流量≥70% |
| SP推荐驱动型 | SP推荐为最大广告来源且占比明显领先 |
| SB品牌拉量型 | SB为最大广告来源或占广告流量≥40% |
| 视频拓量型 | SBV占广告流量≥10%且绝对量不低 |
| 多子体矩阵型 | TOP1＜40%、有效子体≥4 |
| 主力＋辅助型 | TOP1为40%～60%、有效子体≥3 |
| 单爆款驱动型 | TOP1为80%～90% |
| 极端单爆款型 | TOP1≥90% |
| 低量自然型 | 自然占比≥75%，但总流量位于同组尾部 |
| 小规模稳态型 | 总流量偏低，自然占比健康，广告介入适度 |

标签冲突时，以最大风险或最能解释流量来源的标签为主。例如“SB品牌拉量＋单爆款驱动”。

## 8. 风险与优势信号

### 可判定优势

- 大流量＋高自然量：已形成流量规模与自然沉淀；
- 大广告量＋自然量同步强：付费拉量能推动自然承接；
- 多个有效子体：变体资源分配与承接较好；
- SP、SB、SBV组合：多层级触达；
- 推荐绝对量与来源广度同时领先：推荐入口覆盖较强。

### 可判定风险

- 单一爆款下滑会显著拖累父体；
- 广告停止后自然流量可能承压；
- 广告渠道偏科，抗波动能力弱；
- 长尾子体占用变体资源但不贡献有效流量；
- 推荐来源过度集中；
- 小流量导致高占比失真。

### 不可直接判定

- 广告是否盈利；
- Listing转化是否优秀；
- 广告预算是否合理；
- 关键词竞价是否过高；
- 订单与销售额是否增长；
- 具体推广时间与推广节奏。

除非输入包含对应效率、订单、销售或多期趋势数据。

## 9. 结论模板

### 单个竞品

```text
推广类型：{主标签，可加副标签}
推广能力：{强/中强/中/中弱/弱}
流量结构：总流量{数量}，自然流量{数量，占比}，广告流量{数量，占比}。{绝对量与占比综合判断}。
广告打法：以{主要渠道}为主，占广告流量{占比}；{其他有效渠道及结构判断}。
变体结构：TOP1占{占比}，TOP3占{占比}，有效子体{数量}个，属于{结构类型}。
核心优势：{引用至少两个数据证据}。
主要风险：{指出广告、渠道、推荐或变体集中风险}。
可复制打法：{只提出由数据支持的1至3项做法}。
结论置信度：{高/中/低}，原因是{数据完整性与可比性}。
```

### 多竞品核心结论

```text
综合流量运营能力最强：{竞品}，证据为{总流量＋自然沉淀＋变体结构}。
付费拉量最激进：{竞品}，证据为{广告绝对量＋占比＋渠道结构}。
自然沉淀最好：{竞品}，证据为{自然绝对量＋占比}。
变体矩阵最好：{竞品}，证据为{TOP1/TOP3＋有效子体}。
风险最高：{竞品}，证据为{广告依赖/单爆款/单渠道集中}。
```

结论不得只写“较强、较好、合理”；必须说明强在哪里、风险在哪里、数据证据是什么。
